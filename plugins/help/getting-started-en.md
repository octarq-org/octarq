# Getting Started & Platform Overview

Welcome to Octarq! Octarq is a modern multi-tenant, plugin-driven infrastructure & operations platform.

## Key Features

- **Multi-tenant & Workspace Isolation**: Easily manage different teams, projects, and asset ownership.
- **Plugin Architecture**: Modular features like DNS, DDNS, Short Links, Email Routing, and Messaging.
- **Unified API & MCP Protocol**: Native REST API alongside AI-agent friendly Model Context Protocol support.

## Next Steps

1. **Select Workspace**: Switch organizations and workspaces from the top bar.
2. **Explore Plugins**: Navigate to Operations or Infrastructure to configure services.
3. **API Tokens**: Generate tokens under Settings to integrate external CLI tools or scripts.

> [!TIP]
> Press **⌘K** anytime to open the global command palette and jump across features.
