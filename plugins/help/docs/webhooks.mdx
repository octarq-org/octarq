Outbound Webhooks send HTTP `POST` notifications to external servers when events occur in your workspace.

## Key Capabilities

- **Event Notification**: Receive HTTP requests for events such as `email.receive`, `email.send_failed`, and abuse reports.
- **HMAC Signatures**: Each request includes an `X-Octarq-Signature` header calculated using your signing secret and the raw request body.
- **Event Filtering**: Subscribe to specific event topics or use the wildcard `*` to receive all workspace events.

## Register a Webhook Endpoint

1. Go to **Settings → Workspace → Webhooks** (or press `⌘K` / `Ctrl+K` and search "Webhooks").
2. Click **Add Webhook Endpoint**.
3. Enter an **Endpoint Name** and the target **Endpoint URL** (such as `https://api.example.com/hooks/octarq`).
4. (Optional) Provide a **Signing Secret**, or leave empty to auto-generate a secret key.
5. Select **Event Subscriptions** (choose **All Events (*)** or check specific topics).
6. Click **Add Webhook Endpoint**.

## Verify Webhook Signatures

Verify incoming requests on your server by computing the HMAC-SHA256 signature of the raw request body using your secret key and comparing it against the `X-Octarq-Signature` header value:

```javascript
const crypto = require('crypto');

function verifyOctarqWebhook(req, res, next) {
  const signature = req.headers['x-octarq-signature'];
  const expected = crypto
    .createHmac('sha256', process.env.OCTARQ_WEBHOOK_SECRET)
    .update(req.rawBody)
    .digest('hex');

  if (signature === expected) {
    next();
  } else {
    res.status(401).send('Invalid signature');
  }
}
```

## Manage Endpoints

Go to **Settings → Workspace → Webhooks** to inspect signing secrets or delete obsolete endpoints.
