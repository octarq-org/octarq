Learn how workspace switching, command palette navigation, and feature controls work inside the Octarq dashboard.

## Workspaces and Data Scope

- **Workspace Switcher**: Use the dropdown at the top of the left sidebar to switch between personal and organization workspaces.
- **Resource Isolation**: All domains, short links, mailboxes, webhooks, and audit logs belong to the active workspace. Switching workspaces filters all data views to match the selected workspace.

## Command Palette (`⌘K` / `Ctrl+K`)

Press **`⌘K`** (macOS) or **`Ctrl+K`** (Windows/Linux) anywhere in the dashboard to open the command palette.

Use the search bar to jump directly to any page, settings panel, or documentation guide. Note that the command palette navigates pages and does not run creation or deletion commands directly.

## Workspace Roles

Workspace permissions are split into three roles:

- **Owner**: Full workspace management, member role assignments, and workspace deletion.
- **Admin**: Configures workspace features, domains, mailboxes, short links, and member invites.
- **Member**: Uses active workspace features without access to workspace administrative settings.

To manage team members and roles, go to **Settings → Workspace → Members**.

## Toggle Features per Workspace

Go to **Settings → Workspace → Features** (`/settings/plugins`) to turn individual plugins (such as Links, Mail, or DNS) on or off for your workspace. Unused features can be toggled off to clean up sidebar menu items.
