The Octarq management console provides an integrated, developer-first interface for orchestrating short links, transactional emails, DNS zones, API credentials, and team collaboration. This guide introduces the core layout, keyboard shortcuts, navigation patterns, and feature controls.

## Workspace Layout and Navigation

The dashboard layout is divided into three primary functional areas:

1. **Header & Workspace Selector**:
   - Located at the top of the left sidebar.
   - Displays your currently active organization. Click to switch instantly between personal and team workspaces, or to create a new workspace.
2. **Modular Sidebar Navigation**:
   - **Operations**: Day-to-day marketing and communication tools, including [Short Links](/help/short-links) and [Mailboxes](/help/mailboxes).
   - **Infrastructure**: Network orchestration, including [DNS Management](/help/dns) and [Dynamic DNS (DDNS)](/help/ddns).
   - **Settings**: Organization preferences, [API Tokens](/help/api-tokens), [Alerts](/help/notifications), and [Outbound Webhooks](/help/webhooks).
3. **Primary Content Viewport**:
   - Displays high-density data tables, real-time analytics graphs, configuration drawers, and inline documentation.

## Global Command Palette (`⌘K` / `Ctrl+K`)

Accelerate your workflow using the built-in keyboard command palette:

- **Open Palette**: Press **`⌘K`** on macOS or **`Ctrl+K`** on Windows/Linux from any screen in the dashboard.
- **Instant Search**: Type to search across all operational modules, settings panels, and help guides (such as typing "DNS", "Tokens", or "Export").
- **Navigation Safety**: The command palette is optimized for rapid navigation; it never executes destructive actions or mutates data without explicit secondary confirmation modals.
- **Close Palette**: Press `Esc` to return to your previous view.

## Multi-Tenant Data Boundaries

Octarq strictly enforces organizational boundaries:
- Switching the active workspace instantly scopes all visible short links, mailboxes, domain records, and audit events to the selected tenant.
- Team members without explicit permissions in a workspace cannot view its records or enumerate resource IDs.
- For detailed information on member invitations, role matrices, and ownership transfer, refer to the [Organizations & Workspace RBAC](/help/multi-org) guide.

## Dynamic Feature Toggles per Workspace

Octarq allows administrators to tailor the dashboard to match each organization's exact operational needs:

1. Go to **Settings → Workspace → Features** (or navigate directly to `/settings/plugins`).
2. Toggle on the capabilities required for the workspace (e.g. Links, Mail, DNS).
3. Unused features can be switched off to reduce cognitive load; their corresponding sidebar menu items disappear immediately without affecting underlying database records.
