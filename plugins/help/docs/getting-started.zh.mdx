title: 控制台概览
---

介绍 Octarq 管理后台的工作区切换、快捷键导航及功能开关机制。

## 工作区与数据隔离

- **切换工作区**：点击左侧边栏顶部的工作区下拉菜单，可在个人工作区与团队组织之间快速切换。
- **数据隔离**：域名、短链、邮箱、Webhook 和审计日志均绑定在当前选中的工作区内。切换工作区后展示的数据完全隔离。

## 全局命令面板 (`⌘K` / `Ctrl+K`)

在管理后台任意页面按下 **`⌘K`** (macOS) 或 **`Ctrl+K`** (Windows/Linux) 可打开命令面板。

在搜索框中输入页面名称或功能关键字，即可快速跳转目标页面。命令面板仅用于页面搜索与跳转，不直接执行创建或删除操作。

## 角色分工

工作区角色分为三级：

- **Owner（所有者）**：拥有工作区完整管理权限，包括成员角色分配与工作区删除。
- **Admin（管理员）**：可配置工作区设置、域名、邮箱、短链及成员邀请。
- **Member（成员）**：可使用已启用的业务功能，但无法访问工作区管理设置。

管理成员与角色请前往 **设置 → 工作区 → 成员**。

## 按工作区启用与关闭功能

前往 **设置 → 工作区 → 功能**（`/settings/plugins`），可针对当前工作区单独开启或关闭指定插件（如短链、邮箱、DNS）。关闭未使用的功能后，侧边栏对应菜单会自动隐藏。
