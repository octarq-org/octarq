欢迎使用 Octarq 管理控制台！本文档为您提供控制台的基础操作流程、账号权限划分及常见问题排错指南。

## 一、基础操作流程

### 1. 切换与管理工作区
- **组织/工作区选择**：点击控制台左上角工作区下拉菜单，可在多个组织及团队工作区之间秒级切换。
- **资源隔离机制**：域名、短链接、邮箱和 SMTP 发件服务等所有资源均绑定在当前选中的工作区内，切换工作区后展示的数据完全隔离。

### 2. 快捷键与快速导航 (`⌘K` / `Ctrl+K`)
- 在控制台任意页面按下 **`⌘K`** (macOS) 或 **`Ctrl+K`** (Windows/Linux) 可唤起全局命令面板。
- 可直接输入页面名称、功能关键字（如 `DNS`、`短链`、`SMTP`）或域名进行快速搜索与跳转。

## 二、控制台使用注意事项

> [!IMPORTANT]
> **权限控制**：只有工作区 Owner 或 Admin 角色可以新增/删除 DNS 密钥和配置全站邮件路由。普通成员仅支持查看与使用已配好的服务。

> [!WARNING]
> **API Token 安全**：在个人设置中生成的 API Tokens 具备访问对应 API 的完整权限。请勿将 Token 硬编码提交至公开 Git 仓库。

## 三、常见问题解答 (FAQ)

### Q1: 为什么我在左侧菜单看不到部分插件功能？
**答**：Octarq 采用模块化插件架构。如果管理员在实例管理中禁用了某个插件（例如短链接或邮箱），对应菜单将自动隐藏。请联系系统管理员检查插件启用状态。

### Q2: 切换工作区后配置的域名不见了？
**答**：域名与 Zone 配置属于当前工作区的私有资产。请检查左上角当前选中的工作区是否正确。

### Q3: 如何对接外部自动化脚本或 AI Agent (MCP)？
**答**：前往 **个人设置 $\rightarrow$ API Tokens** 生成访问令牌。系统同时原生支持 MCP (Model Context Protocol) 协议，可在 AI Agent 中直接调用控制台能力。
