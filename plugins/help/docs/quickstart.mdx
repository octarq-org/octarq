Deploy and set up an Octarq instance using Docker.

## 1. Run Container

Launch the Octarq single-binary container with persistent volume storage:

```bash
docker run -d \
  --name octarq \
  -p 8080:8080 \
  -v octarq_data:/app/data \
  -e OCTARQ_APP_NAME="My Studio" \
  ghcr.io/octarq-org/octarq:latest
```

Open `http://localhost:8080` in your browser to access the setup wizard.

## 2. Register Admin Account and Workspace

1. Complete the setup wizard to register your **Instance Admin** account.
2. Enter a name to create your first **Organization** (workspace).
3. Additional team members can be invited under **Settings → Workspace → Members**.

## 3. Add a Domain Zone

1. Configure an A or CNAME record in your DNS provider pointing your hostname to your Octarq server IP.
2. In Octarq, go to **Infrastructure → Network → DNS**.
3. Click **+ Add Domain Zone** (or click **Sync Domains** if you connected a Cloudflare/DNSPod provider account).

## 4. Enable Features

1. Go to **Settings → Workspace → Features**.
2. Toggle on the features (such as Links, Mail, or DNS) needed for the workspace.
3. Sidebar navigation menus update immediately when features are toggled on or off.
