Octarq 采用多租户隔离架构。每个组织（工作区）拥有独立的域名、邮箱、短链、API 令牌与成员列表。

## 角色权限

- **Owner（所有者）**：拥有工作区完整管理权限，包括成员角色调整与工作区删除。
- **Admin（管理员）**：可配置域名、邮箱、短链、工作区设置并邀请成员。
- **Member（成员）**：可使用工作区内的业务功能，但无法修改工作区设置。

## 切换工作区

1. 点击左侧边栏顶部的工作区选择器。
2. 在列表中选择目标组织即可完成切换。

## 创建新工作区

1. 打开左侧边栏顶部的工作区选择器。
2. 点击 **+ 创建工作区**。
3. 填写工作区名称（例如 `Acme Corp`）。
4. 点击 **创建并切换**。

## 邀请团队成员

1. 进入 **设置 → 工作区 → 成员**。
2. 点击 **邀请成员**。
3. 填写被邀请人邮箱并指定角色（**Member**、**Admin** 或 **Owner**）。
4. 点击 **发送邀请**。系统将向该邮箱下发激活链接（24 小时内有效）。

## 变更角色与移除成员

在 **设置 → 工作区 → 成员** 中：

- **变更角色**：在成员一行的下拉框中选择新角色。只有 Owner 能够授予或变更 Owner 角色。工作区保留最后一名 Owner 时无法将其降级，需先提升其他成员为 Owner。
- **移除成员**：点击成员旁的 **移除** 即可取消其对当前工作区的访问权限。
