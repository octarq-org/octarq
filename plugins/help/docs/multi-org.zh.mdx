Octarq 采用多租户架构，用户可以创建、管理并在多个相互隔离的**组织**（工作区）之间切换。每个工作区拥有独立的域名、邮箱、短链、API 令牌和成员，并受严格的基于角色的访问控制（RBAC）约束。

## 能力概览

- **严格的多租户隔离**：所有数据实体（短链、邮箱、DNS 区域、Webhook、审计日志）都绑定到具体的组织 ID（`OrgID`），环境之间在逻辑上完全隔离。
- **基于角色的访问控制（RBAC）**：
  - **Owner（所有者）**：工作区的全部管理权限，包括计费、删除工作区和成员管理。
  - **Admin（管理员）**：可管理域名、邮箱、短链、设置与成员。
  - **Member（成员）**：可使用各项业务功能与视图，但没有工作区管理设置权限。
- **无缝切换工作区**：通过侧边栏的工作区选择器在个人与团队工作区之间即时切换，无需重新登录。
- **邮件邀请体系**：按邮箱邀请成员，系统下发有效期 24 小时的安全链接供其设置密码。
- **实例管理员权限**：首个运营账号持有实例级管理权限（`IsInstanceAdmin`），可跨所有组织配置系统设置。

## 使用方法

### 1. 切换工作区
1. 点击左侧边栏顶部的**工作区选择器**。
2. 从列表中选择任一组织，即可切换当前活跃工作区。

### 2. 创建新工作区
1. 打开侧边栏的**工作区选择器**。
2. 点击 **+ 创建工作区**。
3. 填写新工作区名称（例如 `Acme Corp` 或 `Client Project B`）。
4. 点击**创建并切换**。系统会为新组织分配唯一的 URL slug 和入站 Webhook 令牌。

### 3. 邀请团队成员
1. 进入 **设置 → 工作区 → 成员**。
2. 点击**邀请成员**。
3. 填写被邀请人邮箱并指定角色（**Member**、**Admin** 或 **Owner**）。
4. 点击**发送邀请**。对方会收到一封含激活链接的邮件，有效期 24 小时。

### 4. 变更成员角色
在 **设置 → 工作区 → 成员** 中，直接在成员一行的下拉框里选择新角色。控制台会替你守住两条规则：
只有 Owner 能授予或变更 Owner 角色；最后一位 Owner 不能被降级——先提升另一个人为 Owner，再把工作区交出去。

### 5. 撤销成员访问
进入 **设置 → 工作区 → 成员**，点击目标成员的**移除**，即刻收回其对该工作区的访问权限。

:::note
删除某个工作区、或撤销成员在某个组织中的权限，都不会影响他在其他组织中的成员身份和数据。
:::

## 为什么重要

多组织支持让自由职业者、代理商和成长期团队可以在同一套 Octarq 部署中管理多个客户项目、隔离预发与生产环境，或与团队成员协作。
