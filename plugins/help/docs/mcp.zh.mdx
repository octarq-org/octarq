Octarq 内置模型上下文协议（MCP）服务器，允许桌面 AI 客户端及远程 Agent 查询短链、邮件、DNS 记录与系统数据。

## 通道与安全控制

- **本地 stdio 通道**：通过启动 `octarq mcp` 本地子进程供 Claude Desktop 或 Cursor 等桌面应用使用。包含 `query_db_readonly` 工具，支持只读 SQL 查询，并会自动脱敏密码哈希与令牌密钥。
- **HTTP / SSE 通道**：端点位于 `/api/mcp/sse`，面向远程 Agent 接入。使用 [API 令牌](/help/api-tokens)（`Authorization: Bearer oct_...`）进行鉴权，所有工具调用均严格限制在请求方所属的工作区内。出于租户安全考虑，SSE 通道不开放原始 SQL 查询工具。

## 配置本地 stdio 通道 (Claude Desktop)

在 `claude_desktop_config.json` 中配置 Octarq 可执行文件路径：

```json
{
  "mcpServers": {
    "octarq": {
      "command": "/usr/local/bin/octarq",
      "args": ["mcp"],
      "env": {
        "OCTARQ_DB_DSN": "/path/to/octarq.db"
      }
    }
  }
}
```

## 配置远程 SSE 通道

面向远程 AI 工具或网页版客户端：

1. 前往 **设置 → 账户 → API 令牌** 生成一个 [API 令牌](/help/api-tokens)。
2. 在客户端中配置以下连接参数：
   - **SSE 端点**：`https://your-octarq-domain.com/api/mcp/sse`
   - **HTTP 请求头**：`Authorization: Bearer oct_your_secret_api_token`

## 查询示例

连接成功后，可通过自然语言向 AI 提问：

- “汇总今天收到的未读邮件。”
- “统计本月点击量最高的短链。”
- “检查是否存在验证失败的 DNS 记录。”
