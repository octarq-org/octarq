Octarq 内置完整的认证与安全体系，支持邮箱密码登录、两步验证（TOTP 2FA）、OAuth 单点登录（Google 与 GitHub）、密码找回、注册邮箱验证，以及集中式会话管理。

## 能力概览

- **两步验证（TOTP 2FA）**：基于时间的一次性密码（兼容 Google Authenticator、1Password、Authy），并配套 bcrypt 哈希存储的一次性恢复码。
- **OAuth 2.0 集成**：一键启用 Google 与 GitHub 登录。通过 OAuth 登录的用户自动标记为邮箱已验证。
- **密码重置流程**：通过 `/api/auth/forgot` 申请重置链接。令牌以 SHA-256 哈希存储，1 小时后过期。重置成功会自动吊销该账号所有活跃会话。
- **注册邮箱验证**：注册时下发验证链接（`/api/auth/verify-email`），可选择在实例级别强制验证后才允许登录。
- **实例级登录策略**：
  - **开放注册（`allow_registration`）**：开关公开注册（默认开启）。
  - **强制邮箱验证（`require_email_verification`）**：要求用户验证邮箱后才能登录（默认关闭）。
- **会话管理与全局登出**：查看活跃会话（含客户端 IP、归属地、User-Agent），可执行「登出所有设备」立即作废全部 Cookie。

## 使用方法

### 1. 开启两步验证（2FA）
1. 进入 **设置 → 账户 → 安全**（或直接访问 `/settings`）。
2. 在**两步验证（TOTP）**下点击**启用 2FA**。
3. 用验证器 App 扫描二维码（也可手动输入密钥）。
4. 输入 6 位确认码，点击**确认并启用**。
5. **把一次性恢复码保存到安全的地方。** 万一验证器设备丢失，恢复码是唯一的登录途径。

### 2. 找回密码
1. 在登录页点击**忘记密码？**。
2. 输入账号邮箱，点击**发送重置链接**。
3. 打开邮件中的链接（1 小时内有效），设置新密码。
4. 重置成功后所有活跃会话会被终止，需要用新密码重新登录。

### 3. 配置 OAuth 服务商（实例管理员）
1. 进入 **设置 → 实例 → 认证**。
2. 展开 **Google** 或 **GitHub** 配置区。
3. 填入从服务商开发者后台获取的 **Client ID** 与 **Client Secret**。
4. 把 Octarq 显示的**回调 URL** 原样登记到服务商后台（例如 `https://your-octarq.com/api/auth/google/callback`）。
5. 点击**保存**。登录页会自动出现对应的 OAuth 登录按钮。

### 4. 强制策略（实例管理员）
在 **设置 → 实例 → 认证** 中：
- **允许公开注册**：关掉即变为仅邀请制。
- **强制邮箱验证**：开启后，未验证邮箱的账号无法登录，直到完成邮件中的验证。

:::note
通过 OAuth 或 OIDC 登录的用户（Google、GitHub 或企业 SSO）由身份提供方完成校验，会被直接视为邮箱已验证，不再收到验证邮件。
:::

## 为什么重要

一套完整的认证体系能保护你的单人或多人实例，抵御撞库、恶意注册和会话劫持，同时给团队提供无摩擦的 OAuth 登录方式。
