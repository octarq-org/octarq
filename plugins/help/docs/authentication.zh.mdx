Octarq 支持邮箱密码登录、TOTP 两步验证（2FA）、Google 与 GitHub OAuth 单点登录、密码找回以及会话管理。

## 开启两步验证 (2FA)

1. 进入 **设置 → 账户 → 安全**。
2. 在 **两步验证 (TOTP)** 栏目下点击 **启用 2FA**。
3. 使用身份验证器应用（如 Google Authenticator、1Password、Authy）扫描显示的二维码。
4. 输入验证器生成的 6 位数字确认码，点击 **确认并启用**。
5. 将页面生成的一次性恢复码妥善保存到安全位置。

> [!CAUTION]
> 若验证器设备丢失，恢复码是恢复账号登录权限的唯一凭证。

## 重置密码

1. 在登录页面点击 **忘记密码？**。
2. 输入账号邮箱，点击 **发送重置链接**。
3. 查收邮件并打开重置链接（1 小时内有效），设置新密码。
4. 重置成功后，系统会自动终止该账号在所有设备上的活跃登录会话。

## 配置 OAuth 登录（实例管理员）

1. 进入 **设置 → 实例 → 认证**。
2. 展开 **Google** 或 **GitHub** 配置项。
3. 填入服务商开发者后台提供的 **Client ID** 与 **Client Secret**。
4. 将 Octarq 页面显示的 **回调 URL**（`https://your-octarq-domain.com/auth/callback/google`）添加至服务商后台。
5. 点击 **保存**。登录页将自动显示对应的 OAuth 登录按钮。

## 注册与登录策略（实例管理员）

在 **设置 → 实例 → 认证** 中可调整全局策略：

- **允许公开注册**：关闭后暂停开放注册，实例变更为仅限邀请加入。
- **强制邮箱验证**：开启后，未完成邮箱验证的账号将无法登录。

> [!NOTE]
> 通过 OAuth（Google 或 GitHub）登录创建的账号默认会被标记为邮箱已验证。
