Octarq 可将关键系统事件（包括收到邮件、邮件发送失败、滥用举报与安全告警）实时推送到指定的接收渠道。

## 配置 Telegram 告警渠道

1. 在 Telegram 中使用 [@BotFather](https://t.me/BotFather) 创建机器人并复制 **Bot Token**。
2. 将机器人拉入目标 Telegram 群聊或私聊窗口，获取 **Chat ID**。
3. 在 Octarq 中前往 **设置 → 工作区 → 告警**（或按 `⌘K` / `Ctrl+K` 搜索“告警”）。
4. 点击 **添加渠道**，选择 **Telegram Bot**，填入 Bot Token 与 Chat ID 后点击 **保存**。

## 配置 HTTP Webhook 告警渠道

1. 前往 **设置 → 工作区 → 告警**。
2. 点击 **添加渠道**，选择 **自定义 Webhook (HTTP POST)**。
3. 输入目标接收端点 URL（例如 `https://example.com/hooks/alerts`）。
4. 点击 **保存**。

## 测试通知发送

在 **告警** 页面中点击任意已配置渠道旁边的 **测试** 按钮。系统会立即推送一条测试载荷并展示返回的响应状态。

> [!NOTE]
> 通知发送在后台异步处理，即使外部消息接口出现临时网络延迟，也不会拖慢邮件接收与 API 处理流程。
