Octarq sends notifications for system events (such as received emails, mail dispatch errors, abuse reports, and security alerts) to configured messaging channels.

## Configure a Telegram Channel

1. Create a bot using [@BotFather](https://t.me/BotFather) on Telegram and copy its **Bot Token**.
2. Add the bot to your Telegram group or chat, and obtain your **Chat ID**.
3. In Octarq, go to **Settings → Workspace → Alerts** (or press `⌘K` / `Ctrl+K` and search "Alerts").
4. Click **Add Channel**, select **Telegram Bot**, enter your Bot Token and Chat ID, and click **Save**.

## Configure an HTTP Webhook Channel

1. Go to **Settings → Workspace → Alerts**.
2. Click **Add Channel** and select **Custom Webhook (HTTP POST)**.
3. Enter your target endpoint URL (such as `https://example.com/hooks/alerts`).
4. Click **Save**.

## Test Notification Delivery

Click **Test** next to any configured channel on the **Alerts** page. Octarq sends a sample payload immediately and displays the HTTP response status.

> [!NOTE]
> Notification delivery runs asynchronously in the background so that email dispatches and API handlers remain unblocked if external services experience temporary network delays.
