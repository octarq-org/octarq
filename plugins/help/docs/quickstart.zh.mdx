使用 Docker 快速部署并初始化 Octarq 实例。

## 1. 启动容器

使用持久化数据卷启动单二进制容器：

```bash
docker run -d \
  --name octarq \
  -p 8080:8080 \
  -v octarq_data:/app/data \
  -e OCTARQ_APP_NAME="My Studio" \
  ghcr.io/octarq-org/octarq:latest
```

在浏览器中打开 `http://localhost:8080` 进入初始化向导。

## 2. 注册管理员账号与工作区

1. 按向导提示注册首个**实例管理员**账号。
2. 填写组织名称以创建首个**工作区**。
3. 稍后可在 **设置 → 工作区 → 成员** 中邀请其他团队成员。

## 3. 添加域名

1. 在域名解析服务商处添加一条 A 或 CNAME 记录，将目标域名指向 Octarq 服务器 IP。
2. 在 Octarq 中前往 **基础设施 → 网络 → DNS**。
3. 点击 **+ 添加域名 Zone**（若已绑定 Cloudflare 或 DNSPod 账户，也可点击 **同步域名**）。

## 4. 开启功能插件

1. 前往 **设置 → 工作区 → 功能**。
2. 根据工作区需求开启指定功能（如短链、邮箱或 DNS）。
3. 开关变更后，左侧边栏对应菜单会自动更新。
