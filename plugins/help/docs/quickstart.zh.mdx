只需不到五分钟，即可通过 Docker 快速启动一套生产就绪的 Octarq 实例。Octarq 采用现代化单二进制镜像打包，内部集成了轻量高性能嵌入式数据库、Web 控制台前端资源与后台异步任务调度器。

## 第一步：启动 Docker 容器

在您的 Linux 云服务器或本地终端执行以下命令：

```bash
docker run -d \
  --name octarq \
  -p 8080:8080 \
  -v octarq_data:/app/data \
  -e OCTARQ_APP_NAME="生产环境控制台" \
  --restart unless-stopped \
  ghcr.io/octarq-org/octarq:latest
```

### 核心环境变量说明

| 环境变量 | 默认值 | 作用描述 |
|---|---|---|
| `OCTARQ_PORT` | `8080` | 容器内部服务监听的 HTTP 端口。 |
| `OCTARQ_DATA_DIR` | `/app/data` | 持久化数据挂载卷路径，存放 SQLite 数据库及上传资源。 |
| `OCTARQ_APP_NAME` | `Octarq` | 展示在登录页面与系统顶部导航的品牌名称。 |
| `OCTARQ_BASE_DOMAIN` | *(可选)* | 平台共享基础域名，用于生成自动化租户多级子域名。 |

启动成功后，在浏览器中访问 `http://localhost:8080`（或 `http://服务器公网IP:8080`）进入初始化配置向导。

## 第二步：初始化管理员账号与首个工作区

1. **实例管理员注册**：
   - 全新部署后注册的首位用户将自动获得全局 **实例管理员** 权限。
   - 输入管理员邮箱与高强度登录密码。
2. **创建首个组织工作区**：
   - 输入您的团队或组织名称（例如 `Acme Corp`）。
   - 系统将自动完成工作区初始化，并将您设置为该工作区的 **Owner（所有者）**。
3. 随后可在 **设置 → 工作区 → 成员** 中按需邀请其他团队成员协同使用。

## 第三步：绑定并托管自定义域名

若需使用个性化品牌短链接或接收企业邮箱来信，需连接您的域名解析：

1. 在外部公网 DNS 服务商处添加一条 `A` 记录（或 `CNAME` 记录），将目标域名或子域解析至您的 Octarq 服务器公网 IP。
2. 在 Octarq 中前往 **基础设施 → 网络 → DNS**（参见 [DNS 域名解析](/help/dns)）。
3. 点击 **+ 添加域名 Zone** 手动登记域名；亦可进入 **服务商账户** 绑定 Cloudflare 或 DNSPod API Token，点击 **同步域名** 实现全量一键导入。

## 第四步：按需开启功能插件

为当前工作区定制专属功能界面：

1. 进入 **设置 → 工作区 → 功能**（或通过快捷键 `⌘K` 唤起命令面板并搜索 "功能"）。
2. 根据团队实际业务诉求开启对应功能：
   - **短链 (Links)**：品牌短链接生成、智能条件分流与 A/B 分流实验。
   - **邮件 (Mail)**：接入入站邮件 Webhook 与出站事务邮件中继投递。
   - **域名解析 (DNS)**：云服务商解析同步与动态 DNS 令牌。
3. 侧边栏菜单将即时更新呈现已开启的功能模块。
