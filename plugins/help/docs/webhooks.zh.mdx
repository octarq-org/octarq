出站 Webhook 在工作区发生特定事件时，向外部服务器发送 HTTP `POST` 请求。

## 功能说明

- **事件通知**：在收到邮件（`email.receive`）、邮件发送失败（`email.send_failed`）或接收到滥用举报时触发 HTTP 回调。
- **HMAC 签名防篡改**：每个请求包含 `X-Octarq-Signature` 请求头，接收端使用签名密钥与原始 Body 重新计算摘要即可完成来源校验。
- **精细订阅**：可订阅指定的单项事件，或使用通配符 `*` 接收全部工作区事件。

## 注册 Webhook 端点

1. 进入 **设置 → 工作区 → Webhook**（或按 `⌘K` / `Ctrl+K` 搜索“Webhook”）。
2. 点击 **添加 Webhook 端点**。
3. 填写 **端点名称** 与目标 **Endpoint URL**（例如 `https://api.example.com/hooks/octarq`）。
4. （可选）设置 **签名密钥**；留空时系统将自动生成随机密钥。
5. 选择 **订阅事件**（可选择 **全部事件 (*)** 或勾选具体事件）。
6. 点击 **添加 Webhook 端点**。

## 校验 Webhook 签名

接收服务器通过计算原始请求 Body 的 HMAC-SHA256 签名，并与 `X-Octarq-Signature` 请求头进行比对：

```javascript
const crypto = require('crypto');

function verifyOctarqWebhook(req, res, next) {
  const signature = req.headers['x-octarq-signature'];
  const expected = crypto
    .createHmac('sha256', process.env.OCTARQ_WEBHOOK_SECRET)
    .update(req.rawBody)
    .digest('hex');

  if (signature === expected) {
    next();
  } else {
    res.status(401).send('Invalid signature');
  }
}
```

## 管理端点

在 **设置 → 工作区 → Webhook** 中，可随时查看端点密钥或删除停用的 Webhook。
