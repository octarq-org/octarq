API tokens grant non-interactive access to Octarq REST endpoints for scripts, CI/CD pipelines, and external services.

## Overview

- **Token Format**: Tokens begin with an `oct_` prefix followed by 24 cryptographically random bytes (such as `oct_AbC123...`).
- **Storage**: Tokens are stored as SHA-256 hashes. The plain text is shown only once when generated.
- **Expiration**: Tokens can be set to expire after a specified number of days, or set to remain active until manually revoked.
- **Scope & Ownership**: Tokens act with the creator's permissions. Each user manages their own tokens under account settings. Removing a member from a workspace revokes all tokens created by that member.

## Generate an API Token

1. Go to **Settings → Account → API Tokens** (or press `⌘K` / `Ctrl+K` and search "API Tokens").
2. Click **+ New Token**.
3. Enter a **Name** (such as `GitHub Actions` or `Deployment Script`).
4. (Optional) Set a **Note** and an **Expiration (in days)**.
5. Click **Create**.
6. Copy the token immediately. It will not be shown again.

## Use a Token in Requests

Pass the token in the HTTP `Authorization` header as a Bearer token:

```bash
curl -X GET "https://your-octarq-domain.com/api/domains" \
  -H "Authorization: Bearer oct_your_secret_api_token"
```

Example request to create a DNS record:

```bash
curl -X POST "https://your-octarq-domain.com/api/domains/1/records" \
  -H "Authorization: Bearer oct_your_secret_api_token" \
  -H "Content-Type: application/json" \
  -d '{"type":"A","name":"sub","content":"1.2.3.4","ttl":300}'
```

## Revoke a Token

Go to **Settings → Account → API Tokens**, locate the token, and click **Revoke**. Requests using a revoked token receive an HTTP 401 response immediately.
