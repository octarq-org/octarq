API 令牌为脚本、CI/CD 流水线和外部服务提供调用 Octarq REST API 的身份凭据。

## 令牌特性

- **格式规则**：以 `oct_` 为前缀，后接 24 字节随机字符串（例如 `oct_AbC123...`）。
- **安全存储**：数据库中仅保存 SHA-256 哈希值，明文只在创建成功时展示一次。
- **有效期限**：可以设置指定天数后自动失效，也可以不设期限保持长期有效。
- **权限与归属**：令牌继承创建者在工作区内的权限。个人令牌由创建者自行管理；管理员将成员移除出工作区时，该成员创建的令牌会同步失效。

## 创建 API 令牌

1. 前往 **设置 → 账户 → API 令牌**（或按 `⌘K` / `Ctrl+K` 搜索“API 令牌”）。
2. 点击 **+ 新建令牌**。
3. 填写 **名称**（如 `GitHub Actions` 或 `自动化脚本`）。
4. （可选）填写 **备注** 并设置 **有效期（天数）**。
5. 点击 **创建**。
6. 立即复制保存令牌密钥，后续将无法再次查看。

## 使用令牌调用 API

在 HTTP 请求头的 `Authorization` 中传入 Bearer 令牌：

```bash
curl -X GET "https://your-octarq-domain.com/api/domains" \
  -H "Authorization: Bearer oct_your_secret_api_token"
```

调用 API 新建 DNS 记录示例：

```bash
curl -X POST "https://your-octarq-domain.com/api/domains/1/records" \
  -H "Authorization: Bearer oct_your_secret_api_token" \
  -H "Content-Type: application/json" \
  -d '{"type":"A","name":"sub","content":"1.2.3.4","ttl":300}'
```

## 吊销令牌

前往 **设置 → 账户 → API 令牌**，找到对应令牌点击 **吊销**。吊销后使用该令牌发起的 API 请求会立即收到 HTTP 401 报错。
