# 快速入门与平台概览

欢迎使用 Octarq 平台！Octarq 是一个现代化的多组织、插件化基础设施与运维管理平台。

## 核心特性

- **多组织与工作区隔离**：轻松管理不同的团队、项目与资源归属。
- **插件驱动架构**：支持 DNS 管理、动态 DDNS、短链接、邮件路由、消息推送等能力的按需启用与拓展。
- **全站统一 API & MCP 协议**：支持原生 REST API 与 AI 代理集成的 MCP (Model Context Protocol)。

## 快速开始

1. **选择工作区**：在顶部导航栏左侧可快速切换当前所属组织与工作区。
2. **探索插件能力**：进入 Operations / 基础设施等功能区，配置所需服务。
3. **API 与密钥**：在个人设置中生成 API Tokens，对接外部应用或 CLI 工具。

> [!TIP]
> 按快捷键 **⌘K** 可快速召唤全站功能导航面板，在任意页面实现秒级跳转。
