通过标准的 Dyndns2 协议，自动将路由器、NAS 或内网服务器的动态 IPv4 (A) 或 IPv6 (AAAA) 地址同步到 Octarq 托管的 DNS 记录中。

## 创建 DDNS Token

1. 进入 **基础设施 → 网络 → DNS**，切换到 **动态 DNS (DDNS)** 标签页。
2. 点击 **新建 DDNS Token**。
3. 选择目标域名，填写记录名称（例如 `home`），并指定记录类型（`A` 或 `AAAA`）。
4. 点击 **生成 Token**。
5. 立即复制生成的 Secret Token 与更新 URL。明文令牌仅在创建成功时展示一次。

> [!CAUTION]
> 数据库仅保存 Token 的 SHA-256 哈希。如果丢失 Token，需要撤销并重新生成。

## 客户端配置示例

### 使用 `curl` 设置定时任务

在 Linux 服务器或路由器中添加定时任务，自动检测外网出口 IP 并提交更新：

```bash
curl -s "https://your-octarq-domain.com/api/dns/ddns/update?hostname=home.example.com&key=YOUR_SECRET_TOKEN"
```

### 路由器与 NAS 填报参数

在 OpenWrt、群晖 NAS 或 `ddclient` 等客户端中设置以下参数：

- **服务提供商**: `Dyndns2` 或 `Custom`
- **服务器**: `your-octarq-domain.com`
- **更新 URL / 路径**: `/api/dns/ddns/update?hostname=[DOMAIN]&key=[PASSWORD]`
- **主机名 / 用户名**: `home.example.com`
- **密码**: 生成的 Secret Token

## 撤销密钥与手动指定 IP

- **撤销 Token**：若设备遗失或密钥泄露，在 DDNS 列表中点击 **撤销 Token** 即可阻止后续更新。
- **手动指定 IP**：在更新 URL 末尾追加 `&ip=1.2.3.4` 或 `&ip=2001:db8::1` 即可显式指定目标 IP。
