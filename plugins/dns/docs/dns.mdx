Link Cloudflare or DNSPod provider tokens, sync domain zones, edit DNS records, and check email and short link DNS configurations.

## Add Provider Accounts

1. Go to **Infrastructure → Network → DNS** and click the **Provider Accounts** tab.
2. Click **Add Provider Account** and select `Cloudflare` or `DNSPod`.
3. Enter your API token and save. Credentials are encrypted at rest using AES-GCM.

> [!CAUTION]
> Cloudflare API tokens must include `Zone - Zone:Read` and `Zone - DNS:Edit` permissions.

## Sync Domains and Manage Records

1. Click **Sync Domains** on the DNS page to fetch active zones from connected provider accounts.
2. Select a domain from the left list to view and manage its A, AAAA, CNAME, TXT, MX, and NS records.
3. Toggle the **Proxied** switch on Cloudflare records to turn CDN proxying and SSL protection on or off.

## Run DNS Verification

1. Select a domain and click **Verify DNS**.
2. Octarq performs DNS queries for:
   - **SPF**: Checks for valid `v=spf1` TXT records.
   - **DMARC**: Checks `_dmarc` policy TXT records.
   - **DKIM**: Inspects configured DKIM selectors.
   - **Link CNAME**: Resolves short link subdomain CNAME targets.

> [!WARNING]
> When a short link subdomain has Cloudflare proxying (orange cloud) enabled, Cloudflare flattens CNAME responses to IP addresses. The status might show "Unverified", but short link redirects continue to work.
