This guide walks you through linking DNS provider API tokens, syncing domain zones, managing records, and executing automated health verifications inside the Octarq Console.

## 1. Step-by-Step Console Procedures

### 1. Linking DNS Provider API Tokens
1. Go to **Infrastructure $\rightarrow$ Domains**, and click **Provider Accounts** (or **Settings $\rightarrow$ Provider Accounts**).
2. Click **Add Provider Account**, and select your provider type (`Cloudflare` or `DNSPod`).
3. Enter your API Token and save. Credentials are encrypted at rest using AES-GCM.

> [!CAUTION]
> **Cloudflare API Token Scope**: Ensure your Cloudflare API Token includes `Zone - Zone:Read` and `Zone - DNS:Edit` permissions. Without these, zone fetching and record updates will fail.

### 2. Domain Sync & Record Editing
1. Click **Sync Domains** on the domain overview page to fetch all active zones from connected provider accounts.
2. Select any domain to manage A, AAAA, CNAME, TXT, MX, and NS records directly from the Octarq console table.
3. **Cloudflare CDN Proxy Toggle**: Toggle the **Proxied** badge on any Cloudflare record to enable or disable HTTP caching and SSL proxying.

### 3. Running DNS Health Verifications
1. Open your domain details and click **Verify DNS**.
2. Octarq performs real-time DNS queries for:
   - **SPF**: Inspects for valid `v=spf1` TXT records.
   - **DMARC**: Checks `_dmarc` policy TXT records.
   - **DKIM**: Inspects configured DKIM selectors.
   - **Link CNAME**: Resolves short-link subdomain CNAME targets.

---

## 2. Important Operating Cautions

> [!WARNING]
> **Cloudflare CNAME Flattening**: When short-link subdomains have the Cloudflare orange cloud (Proxied) turned ON, Cloudflare flattens CNAME responses to IP addresses. The verification status may show "Unverified" as expected; actual URL redirection remains completely functional.

---

## 3. Frequently Asked Questions (FAQs)

### Q1: Why does domain sync return "Invalid API Token"?
**Answer**: Double check that your API Token hasn't expired or restricted source IPs. For DNSPod, ensure the credentials follow the `ID,Token` format.

### Q2: How long do DNS record changes take to propagate?
**Answer**: Edits pushed in Octarq update provider APIs instantly. Public DNS propagation depends on record TTLs (typically 1–5 minutes).
