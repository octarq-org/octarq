Update A (IPv4) and AAAA (IPv6) DNS records automatically from routers, NAS devices, or local servers using standard Dyndns2 protocol endpoints.

## Create a DDNS Token

1. Go to **Infrastructure → Network → DNS** and open the **Dynamic DNS (DDNS)** tab.
2. Click **New DDNS Token**.
3. Select your domain, enter a record name (such as `home`), and pick the record type (`A` or `AAAA`).
4. Click **Create Token**.
5. Copy the generated secret token and update URL immediately. The cleartext secret is displayed only once.

> [!CAUTION]
> The database stores only a SHA-256 hash of the secret token. If you lose the token, you will need to revoke it and generate a new one.

## Client Configuration

### Cron Job with `curl`

Run a scheduled cron job on Linux servers or routers to auto-detect public IP and push updates:

```bash
curl -s "https://your-octarq-domain.com/api/dns/ddns/update?hostname=home.example.com&key=YOUR_SECRET_TOKEN"
```

### Router and NAS Setup

In router or NAS DDNS client settings (such as OpenWrt, Synology, or `ddclient`):

- **Service Provider**: `Dyndns2` or `Custom`
- **Server**: `your-octarq-domain.com`
- **Path / Update URL**: `/api/dns/ddns/update?hostname=[DOMAIN]&key=[PASSWORD]`
- **Username / Hostname**: `home.example.com`
- **Password**: Your secret token

## Token Revocation and Manual IP Override

- **Revoke Token**: If a device or token key is compromised, find the token in the Dynamic DNS table and click **Revoke Token** to block subsequent update requests.
- **Pass Explicit IP**: Append `&ip=1.2.3.4` or `&ip=2001:db8::1` to the update URL to override automatic IP detection.
