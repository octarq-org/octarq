---
title: 域名与 DNS 管理
---

绑定 Cloudflare 或 DNSPod API 密钥、一键同步域名、管理解析记录，并对邮件与短链相关的 DNS 进行校验。

## 绑定服务商账户

1. 进入 **基础设施 → 网络 → DNS**，切换到 **服务商账户** 标签页。
2. 点击 **添加服务商账户**，选择 `Cloudflare` 或 `DNSPod`。
3. 输入 API Token 并保存。密钥采用 AES-GCM 加密存储。

> [!CAUTION]
> Cloudflare API Token 需开启 `Zone - Zone:Read` 和 `Zone - DNS:Edit` 权限。

## 同步域名与管理记录

1. 在 DNS 页面点击 **同步域名**，系统会自动拉取已绑定账号下的托管域名。
2. 在左侧列表中选择域名，管理 A、AAAA、CNAME、TXT、MX、NS 记录。
3. 勾选或取消 Cloudflare 记录的 **Proxied** 开关，开启或关闭 CDN 代理防护。

## 运行 DNS 校验

1. 选择目标域名，点击 **校验 DNS**。
2. 系统会探测以下解析状态：
   - **SPF**：检查是否存在有效 `v=spf1` TXT 记录。
   - **DMARC**：校验 `_dmarc` 策略记录。
   - **DKIM**：探测指定的 DKIM 签名 Selector。
   - **短链 CNAME**：检查短链子域名是否正确指向目标地址。

> [!WARNING]
> 短链子域名开启 Cloudflare 代理（橙色云朵）时，CNAME 记录会被 Cloudflare 展平为 IP 地址。控制台可能显示“未验证”，但不影响实际短链跳转。
