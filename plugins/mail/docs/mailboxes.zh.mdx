接收事务性入站邮件、配置 Catch-All 邮箱路由、查看原始 EML 邮件，以及设置出站 SMTP 发件服务。

## 接入入站邮件 Webhook

1. 进入 **日常运营 → 消息 → 邮件**，切换至 **Settings** 标签页。
2. 在 **入站配置** 下复制当前工作区的 **入站 Webhook URL** (`/api/webhook/{orgSlug}/email/inbound/{token}`)。
3. 在 Cloudflare Email Routing Workers 等邮件服务中，配置脚本将收到的原始邮件 POST 至该 Webhook 地址。
4. 配置完成后，发送至自定义域名的邮件将直接呈现在 **Mail** 邮箱收件箱中。

## Catch-All 路由与保留前缀

1. 进入 **日常运营 → 消息 → 邮件**，切换至 **Settings** 标签页。
2. 在 **入站配置** 中开启 **启用 Catch-All 路由**。
3. 在 **保留邮箱前缀** 中填写用逗号分隔的前缀（如 `admin, support, postmaster`），防止系统保留地址被 Catch-All 路由误拦截。

## 配置出站 SMTP 发件服务

1. 进入 **日常运营 → 消息 → 邮件**，切换至 **Settings** 标签页，找到 **SMTP 发件配置** 区域。
2. 点击 **添加 SMTP 发件服务**。
3. 填入 SMTP 服务器主机（如 `smtp.mailgun.org`）、端口（如 `587`）、用户名、密码及默认发件人邮箱。
4. 点击 **保存**。密码将在后端通过 AES-GCM 加密存储。

> [!NOTE]
> 系统事务邮件（如成员邀请函、密码重置邮件）会默认使用当前工作区中配置的第一条有效 SMTP 发件服务。
