Create branded short URLs, set up conditional targeting rules by location, device, or language, and configure link passwords or expiration limits.

## Create a Short Link

1. Go to **Operations → Marketing → Links** (or press `⌘K` / `Ctrl+K` and search "Links").
2. Click **New Link**.
3. Enter the destination **Target URL** (such as `https://example.com/page`).
4. (Optional) Select a custom domain and enter a custom slug.
5. Click **Create**.

## Conditional Targeting Rules

When creating or editing a short link, click **Add Rule** to set conditional redirects:

- **GeoIP Location**: Route visitors by country code (for example, send `US` traffic to a US landing page).
- **Device & OS**: Route mobile users (iOS or Android) directly to app store links.
- **Browser Language**: Match accept-language headers (for example, `zh-CN` to a Chinese page).

## Passwords and Limits

- **Password Protection**: Visitors must enter a passcode before redirecting.
- **Expiration and Click Limits**: Set an expiration date or total click limit. Once reached, visitors redirect to an **Expired URL**.

> [!CAUTION]
> System prefixes (`/admin`, `/api`, `/assets`, `/portal`) are reserved and cannot be used as short link slugs.

## Enable Auto-Wrapping in Outgoing Mail

To automatically wrap external URLs in outbound emails, go to **Operations → Messaging → Mail**, open the **Settings** tab, and turn on **Auto-wrap links in outgoing mail** under **Inbound Configuration**.
