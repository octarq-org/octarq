创建短链接，配置按国家地区、设备类型及语言的分流规则，并可设置密码保护与访问上限。

## 创建短链接

1. 进入 **日常运营 → 营销 → 短链**（或按 `⌘K` / `Ctrl+K` 搜索“短链”）。
2. 点击 **新建短链**。
3. 输入 **目标地址 (Target URL)**（例如 `https://example.com/page`）。
4. （可选）选择自定义域名与自定义 Slug。
5. 点击 **创建**。

## 条件分流规则

创建或编辑短链时，可点击 **添加规则** 设置重定向条件：

- **地理位置 (GeoIP)**：按国家代码分流（例如将 `US` 访客重定向至英文落地页）。
- **设备与操作系统**：将移动端（iOS 或 Android）访客分流至对应的应用商店。
- **浏览器语言**：按语言请求头（如 `zh-CN`）分流至对应的语言页面。

## 密码保护与限制

- **密码保护**：开启后，访客需输入密码才能完成跳转。
- **过期时间与点击上限**：可设置过期时间或总点击次数。达到阈值后，访客将被重定向至指定的 **过期回退地址**。

> [!CAUTION]
> 系统内置路径前缀（如 `/admin`、`/api`、`/assets`、`/portal`、`/help`）属于保留字，无法作为短链接 Slug。

## 在邮件中开启短链自动包装

若需自动将发出的邮件中的外部链接转换为短链，可前往 **日常运营 → 消息 → 邮件**，切换至 **Settings** 标签页，在 **入站配置** 下勾选 **出站邮件自动短链化**（Auto-wrap links in outgoing mail）。
