# Origin Substrate Engineering Specification (SPEC.md)

## 1. Module Identity & Purpose

- **Package**: `github.com/octarq-org/octarq/server/origin`
- **Substrate Role**: Ingress, URL Resolution, Host Header Security & Multi-Tenant Routing Anchor
- **Fail-Closed Mode**: Strictly rejects untrusted Host headers and unknown hostnames; never reflects unauthenticated host headers into absolute URL generation (anti-CWE-640).

## 2. Architecture & Responsibilities

The `origin` package derives the absolute origin (`https://<host>`) for outbound URLs generated by the system (password resets, invitation links, email verifications, OAuth redirect URIs).

### Decomposition Architecture
- `origin.go`: Core host normalization, matching algorithm, candidate tree generator, and table query mirrors.
- `cache.go`: Thread-safe bounded cache with namespace isolation (`*sql.DB` pointer prefix), TTL expiration (5 minutes), and domain/base invalidation hooks.
- `resolver.go`: The `Resolver` state object exposing high-concurrency cached queries for web handlers.

```
        |                                 |
        v                                 v

        |                                 |
        +----------------+----------------+

                         v

              (Whitelist present in DB?)
                /                  \
             YES                    NO

         (Fail-Closed)         /           \
                            YES             NO
                             |               |
                         http(s)://lb    Reject ("")
```

## 4. Invariants & Security Constraints

1. **Host Header Poisoning Defense (CWE-640)**: The `Host` HTTP header is treated solely as a lookup selector against proven owned domains or explicit operator configuration (`OCTARQ_SHARED_HOSTS`).
2. **Loopback Isolation**: When no registered domains exist, only verified loopback addresses (`localhost`, `127.0.0.1`, `[::1]`, `*.localhost`) with strictly valid numeric ports are allowed.
3. **Database Namespace Separation**: The in-memory cache namespaces every query key by database pointer (`fmt.Sprintf("%p|", sqlDB)`), ensuring isolated test execution without cross-test cache contamination.
4. **Reserved Subdomain Zone**: Subdomains under the reserved tenant base (`models.BaseDomain`) cannot bubble up to apex or match across arbitrary host lists.
