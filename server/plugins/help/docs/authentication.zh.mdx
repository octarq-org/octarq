Octarq 提供账户与身份控制功能，保护工作区与团队成员的安全。你可以使用邮箱和密码登录、开启双因素认证、重置密码、配置 OAuth 快捷登录，以及管理实例的注册策略。

## 使用邮箱与密码登录

Octarq 保护你的账户凭证与活跃会话：

- **密码存储**：密码采用加密存储并配备独立盐值，系统绝不记录或存储明文密码。
- **会话管理**：登录会话使用安全 Cookie 管理，注销时会立即终止会话。

## 开启双因素认证 (TOTP)

使用基于时间的一次性密码为账户增加二次安全校验：

1. 前往 **设置 → 账户 → 安全**。
2. 在 **双因素认证** 下点击 **启用 2FA**。
3. 使用身份验证器应用（如 1Password、Google Authenticator 或 Apple 钥匙串）扫描屏幕上的二维码。
4. 输入验证器生成的 6 位验证码，点击 **确认并启用**。
5. 将显示的 10 组一次性应急恢复码妥善保存在密码管理工具中。

:::caution 妥善保存应急恢复码
若丢失身份验证器设备，应急恢复码是自行恢复账户访问权限的唯一方式。每组恢复码仅可使用一次。
:::

## 重置账户密码

通过邮箱验证恢复账户密码：

1. 在登录页面点击 **忘记密码？**。
2. 输入账户邮箱地址，点击 **发送重置链接**。
3. 打开收到的邮件，在 1 小时内点击重置链接。
4. 输入并确认新密码。
5. 使用新密码登录。Octarq 会自动终止该账户在其他设备上的所有活跃会话。

## 配置 OAuth 登录

实例管理员可以为团队成员配置 Google 和 GitHub 快捷登录：

1. 前往 **设置 → 实例 → 认证**。
2. 展开 **Google** 或 **GitHub** 配置项。
3. 输入应用凭据的 **Client ID** 和 **Client Secret**（凭据均加密存储）。
4. 在服务商控制台中添加回调地址：
   - Google: `https://your-octarq-host.com/auth/callback/google`
   - GitHub: `https://your-octarq-host.com/auth/callback/github`
5. 点击 **保存**。登录页面将立即显示快捷登录按钮。通过 OAuth 登录的账户会自动完成邮箱验证。

## 管理注册与访问策略

实例管理员可以在 **设置 → 实例 → 认证** 中配置新成员准入规则：

- **允许公开注册**：关闭后将实例转为邀请制，新用户必须通过管理员邀请加入。
- **要求邮箱验证**：开启后，用户必须先完成邮箱验证链接才能登录使用。

:::note 企业级单点登录 (SSO)
Octarq Pro 提供企业级单点登录 (SSO)，支持通过 SAML 2.0 和 OpenID Connect (OIDC) 对接 Okta、Microsoft Entra ID、Keycloak 和 Google Workspace，并支持自动化用户配置。
:::
