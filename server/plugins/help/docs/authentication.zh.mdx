Octarq 提供了符合现代安全标准的用户身份鉴权与访问控制框架，保护开发者工作区资产与团队成员身份安全。系统支持邮箱密码登录、基于时间戳的 TOTP 双因素认证 (2FA)、一次性应急恢复码、自助重置密码、第三方社交登录 (Google 与 GitHub) 以及实例级注册策略。

## 邮箱与密码身份认证

- **密码单向哈希加盐**：用户密码采用现代高强度散列算法（Argon2id/bcrypt）单向哈希加密，每个账号配备独立盐值。系统绝不在任何日志或数据库中明文记录密码。
- **会话 Cookie 安全防护**：已认证的 Web 登录会话采用带有 `HttpOnly`、`SameSite=Lax` 与 `Secure` 属性的安全 Cookie 进行管理，注销时在服务端立即销毁对应 Session 会话凭证。

## TOTP 双因素认证 (2FA)

为账号增设二次校验屏障，有效抵御密码泄露风险：

1. 进入 **设置 → 账户 → 安全**。
2. 在 **双因素认证 (TOTP)** 区域点击 **启用 2FA**。
3. 使用移动端身份验证器 App（如 1Password、Google Authenticator、Microsoft Authenticator 或 iOS 自带密码管理）扫描页面展示的二维码。
4. 输入验证器当前呈现的 6 位动态数字码，点击 **确认并启用**。
5. **保存应急恢复码**：系统将展示 10 组一次性应急恢复码。请将其复制并保存在离线安全保险箱中。

:::caution 必须备份应急恢复码
若您的移动端验证器设备损坏、丢失或误删，应急恢复码是您自行找回账号登录权限的**唯一**凭证。每组恢复码仅可成功使用一次。
:::

## 自助密码找回与全端会话吊销

当成员遗忘账号密码时：

1. 在登录界面点击 **忘记密码？**。
2. 输入已注册的账号邮箱并提交请求。
3. Octarq 将自动下发包含加密签名令牌的重置邮件，该链接在 **1 小时** 内有效。
4. 用户在打开的页面中设置新密码。
5. **全端强制下线保护**：修改密码成功后，系统会自动吊销该用户此前在所有浏览器与移动端设备上的活跃会话凭据，强制重新使用新密码登录。

## 配置 OAuth 快捷登录（实例管理员）

为团队成员提供无感快捷的第三方账号登录能力：

1. 进入 **设置 → 实例 → 认证**。
2. 展开 **Google** 或 **GitHub** 配置折叠项。
3. 填入在各开放平台开发者后台申请的凭证：
   - **Client ID**：OAuth 应用的公钥客户端 ID。
   - **Client Secret**：对应的机密密钥（后端通过 AES-GCM 算法加密存储）。
4. 在服务商后台将回调地址精确配置为 Octarq 提示的 URI：
   - Google: `https://your-octarq-host.com/auth/callback/google`
   - GitHub: `https://your-octarq-host.com/auth/callback/github`
5. 点击 **保存**。登录界面将即时呈现对应的 OAuth 快捷登录按钮。
6. **自动邮箱验证**：通过受信任的 OAuth 服务商登录创建的账号，将自动打上邮箱已验证标记。

## 实例级用户注册与登录策略

实例管理员可在 **设置 → 实例 → 认证** 中调整全局安全准入规则：

- **允许公开注册**：关闭后停止公开注册入口，实例将转变为纯邀请制部署，仅允许受邀成员注册。
- **强制邮箱验证**：开启后，未通过邮箱验证链接激活的账号将被阻止登录系统。

:::caution 本功能为 Pro 专属功能
针对企业级统一身份目录整合，Octarq Pro 提供了企业级单点登录 (Enterprise SSO) 模块，原生支持通过 OIDC (OpenID Connect) 或 SAML 2.0 协议无缝对接 Okta、Azure AD / Entra ID、Keycloak 及 Google Workspace，并支持 JIT 即时账号自动配置。
:::
