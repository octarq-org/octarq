Octarq provides an alerting engine that monitors workspace events—such as received transactional emails, delivery failures, and DNS verification changes—and dispatches notifications to external messaging channels.

## Connect a Telegram Bot

1. Open Telegram, search for [@BotFather](https://t.me/BotFather), and send `/newbot` to create your bot. Copy the **Bot Token**.
2. Add your bot to a Telegram group or channel, or start a direct chat with it.
3. Find the destination **Chat ID** (group IDs usually start with a negative number).
4. In Octarq, go to **Settings → Workspace → Alerts** (or press `⌘K` / `Ctrl+K` and search "Alerts").
5. Click **Add Channel**, select **Telegram Bot**, enter the **Bot Token** and **Chat ID**, and click **Save**.

## Connect a Custom Webhook

1. Go to **Settings → Workspace → Alerts**.
2. Click **Add Channel** and select **Custom Webhook (HTTP POST)**.
3. Enter your destination **Endpoint URL** (such as `https://alerts.example.com/octarq`).
4. Click **Save**. Octarq dispatches structured JSON payloads with event severity, timestamp, and details.

## Test Alert Delivery

1. Go to **Settings → Workspace → Alerts**.
2. Find your configured channel in the list and click **Test Delivery**.
3. Octarq sends a test alert payload to your endpoint.
4. Check the displayed HTTP status code, latency, and any upstream error messages.

## Protect Delivery Security

- **Network protection**: Webhook destinations are checked automatically. Requests to private or local network addresses are blocked to protect your infrastructure.
- **Background delivery**: Alerts are processed asynchronously with a 10-second timeout. Upstream service delays will not slow down incoming mail delivery or link redirects.
