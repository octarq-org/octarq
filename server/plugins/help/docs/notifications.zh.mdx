Octarq 提供业务告警与通知推送功能。当工作区发生关键事件（例如收到事务邮件、发信失败或 DNS 状态变更）时，系统可实时将告警信息推送到指定的外部通讯渠道。

## 配置 Telegram 机器人

1. 在 Telegram 中搜索 [@BotFather](https://t.me/BotFather)，发送 `/newbot` 创建机器人，并复制生成的 **Bot Token**。
2. 将机器人拉入 Telegram 群组或频道，或向机器人发起私聊。
3. 获取接收目标的 **Chat ID**（群组 ID 通常为负数）。
4. 在 Octarq 中进入 **设置 → 工作区 → 告警**（或按 `⌘K` / `Ctrl+K` 搜索“告警”）。
5. 点击 **添加渠道**，选择 **Telegram Bot**，输入 **Bot Token** 与 **Chat ID**，然后点击 **保存**。

## 配置自定义 Webhook

1. 前往 **设置 → 工作区 → 告警**。
2. 点击 **添加渠道** 并选择 **自定义 Webhook (HTTP POST)**。
3. 输入目标端点的 **Endpoint URL**（例如 `https://alerts.example.com/octarq`）。
4. 点击 **保存**。Octarq 将以结构化 JSON 发送包含事件等级、时间戳与详情的通知。

## 测试告警发送

1. 前往 **设置 → 工作区 → 告警**。
2. 在列表中找到已配置的渠道，点击 **测试发送**。
3. Octarq 会向该目标发送一条测试通知。
4. 查看页面反馈的 HTTP 状态码、响应耗时以及服务商返回的错误信息。

## 了解推送安全与保障

- **网络安全防护**：系统会自动校验 Webhook 目标地址，拦截指向本地或私有内网的请求，保护内部网络安全。
- **后台异步推送**：告警采用后台异步处理并设有 10 秒超时限制，外部通讯服务的网络波动不会影响邮件接收或短链跳转。
