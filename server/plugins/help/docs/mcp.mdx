Octarq includes a built-in Model Context Protocol (MCP) server that lets Large Language Models (LLMs), IDE assistants, and autonomous agents interact with your workspace data, short links, mailboxes, and DNS records.

## Choose a Connection Mode

Octarq provides two standard connection methods:

- **Local stdio connection**: For local desktop assistants like Claude Desktop and Cursor running on your machine. Runs directly with `octarq mcp`.
- **Remote HTTP and SSE connection**: For remote AI agents and cloud workflows. Connects to `https://your-octarq-host.com/api/mcp/sse` using an [API token](/help/api-tokens) (`Authorization: Bearer oct_...`). Requests are scoped strictly to the organization tied to the token.

:::note Structured Tools
Octarq exposes structured tools rather than raw SQL access. This keeps actions safe and ensures tenant boundaries are maintained across workspaces.
:::

## Available Tools

The MCP server provides the following tools across both stdio and SSE connections:

- **`create_shortlink`**: Create a short link with target URL, optional slug, domain host, passcode, and expiration.
- **`list_links`**: Search and list short links in the active workspace with limits and search filters.
- **`list_domains`**: View managed domain zones and DNS verification status (SPF, DKIM, DMARC).
- **`list_mailboxes`**: View mailboxes, email addresses, and unread counts.
- **`list_emails`**: List recent incoming transactional emails with subject, sender, and snippet.
- **`get_latest_otp`**: Extract one-time verification codes (OTP) from recent unread emails received in the last 10 minutes.
- **`get_email_summary`**: Get a structured, sanitized summary of an email with category and detected codes.
- **`get_email_content`**: Get sanitized plain text email body content with sensitive links redacted.
- **`export_data`**: Export workspace records (links, emails, domains, or mailboxes) as JSON.

## Read Operational Resources

AI clients can read live workspace resources:

- **`octarq://metrics/traffic`**: Real-time link redirect and click statistics for the current workspace.
- **`octarq://domains/health`**: DNS status and verification health for all managed domains.

## Connect Claude Desktop

1. Open your Claude Desktop configuration file (`~/Library/Application Support/Claude/claude_desktop_config.json` on macOS or `%APPDATA%\Claude\claude_desktop_config.json` on Windows).
2. Add the `octarq` server definition:
   ```json
   {
     "mcpServers": {
       "octarq": {
         "command": "/usr/local/bin/octarq",
         "args": ["mcp"],
         "env": {
           "OCTARQ_DB_DSN": "/var/lib/octarq/data.db"
         }
       }
     }
   }
   ```
3. Restart Claude Desktop.

## Connect Cursor IDE

1. Open your project root directory and create or edit `.cursor/mcp.json`.
2. Add the remote Octarq connection:
   ```json
   {
     "mcpServers": {
       "octarq-remote": {
         "url": "https://your-octarq-host.com/api/mcp/sse",
         "headers": {
           "Authorization": "Bearer oct_your_secret_api_token"
         }
       }
     }
   }
   ```
3. Save the file and restart Cursor.

## Use Natural Language Prompts

Once connected, your AI assistant can execute operations using conversational prompts:

- "Create a short link pointing to https://example.com/docs with slug docs on go.example.com"
- "Check the verification status of all domains in my workspace"
- "Find the verification code received in my support mailbox within the last 5 minutes"
