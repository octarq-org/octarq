Octarq includes a built-in Model Context Protocol (MCP) server. It lets AI assistants read and query your workspace through the installed plugins.

## Choose a Connection Mode

Octarq provides two standard connection methods:

- **Local stdio connection**: For local desktop assistants like Claude Desktop and Cursor running on your machine. Runs directly with `octarq mcp`.
- **Remote HTTP and SSE connection**: For remote AI agents and cloud workflows. Connects to `https://your-octarq-host.com/api/mcp/sse` using an [API token](/help/api-tokens) (`Authorization: Bearer oct_...`). Requests are scoped strictly to the organization tied to the token.

:::note Structured Tools
Octarq exposes structured tools rather than raw SQL access. This keeps actions safe and ensures tenant boundaries are maintained across workspaces.
:::

## Available Tools

The core server provides these tools across both stdio and SSE connections:

- **`octarq_infra__describe_tenant_schema`**: List the tenant views and their columns.
- **`octarq_infra__query_db_readonly`**: Run a read-only SELECT query against the tenant views.
- **`octarq_infra__export_data`**: Export workspace records as JSON.
- **`octarq_infra__notify`**: Send a message to a configured alert channel.

Installed feature plugins add their own tools. Tool names use the `octarq_<area>__<action>` form.

## Connect Claude Desktop

1. Open your Claude Desktop configuration file (`~/Library/Application Support/Claude/claude_desktop_config.json` on macOS or `%APPDATA%\Claude\claude_desktop_config.json` on Windows).
2. Add the `octarq` server definition:
   ```json
   {
     "mcpServers": {
       "octarq": {
         "command": "/usr/local/bin/octarq",
         "args": ["mcp"],
         "env": {
           "OCTARQ_DB_DSN": "/var/lib/octarq/data.db"
         }
       }
     }
   }
   ```
3. Restart Claude Desktop.

## Connect Cursor IDE

1. Open your project root directory and create or edit `.cursor/mcp.json`.
2. Add the remote Octarq connection:
   ```json
   {
     "mcpServers": {
       "octarq-remote": {
         "url": "https://your-octarq-host.com/api/mcp/sse",
         "headers": {
           "Authorization": "Bearer oct_your_secret_api_token"
         }
       }
     }
   }
   ```
3. Save the file and restart Cursor.

## Use Natural Language Prompts

Once connected, your AI assistant can execute operations using conversational prompts:

- "List the columns of the tenant views in my workspace"
- "Export my workspace records as JSON"
- "Send a test message to the alerts channel"
