Octarq API tokens let you authenticate scripts, CI/CD pipelines, and remote agents without sharing your account password. Every token is scoped to your active workspace and restricted by your member role.

## Create an API Token

1. Go to **Settings → Account → API Tokens** (or press `⌘K` / `Ctrl+K` and search "API Tokens").
2. Click **New Token**.
3. Configure the token options:
   - **Name**: Enter a descriptive label, such as `GitHub Actions` or `Deploy Script`.
   - **Role**: Choose `Member`, `Admin`, or `Owner`. You cannot grant a role higher than your own workspace role.
   - **Expiration**: Choose 7, 30, 90 days, or leave it blank for a non-expiring token.
   - **Note**: (Optional) Add context about where the token is used.
4. Click **Create Token**.
5. Copy the displayed secret token immediately. Octarq stores tokens encrypted at rest and never displays the secret again.

## Choose a Role Scope

Every API token enforces role-based access control (RBAC) within your workspace:

- **Member**: Standard operational access to create and manage short links, mailboxes, and domain records.
- **Admin**: Operational access plus workspace settings, DNS providers, Webhook endpoints, and alerts.
- **Owner**: Full workspace access, including member invitations, billing, and workspace deletion.

:::note Role Limits
You can only issue tokens with permissions up to your own workspace role. If you are an Admin, you cannot create an Owner token.
:::

## Authenticate API Requests

Include your API token in the standard HTTP `Authorization` header with the `Bearer` prefix:

```http
Authorization: Bearer oct_your_secret_api_token
```

### List Domains

```bash
curl -s -X GET "https://your-octarq-host.com/api/domains" \
  -H "Authorization: Bearer oct_your_secret_api_token" \
  -H "Accept: application/json"
```

### Create a Short Link

```bash
curl -s -X POST "https://your-octarq-host.com/api/links" \
  -H "Authorization: Bearer oct_your_secret_api_token" \
  -H "Content-Type: application/json" \
  -d '{
    "target": "https://example.com/docs",
    "slug": "docs"
  }'
```

## Revoke an API Token

1. Go to **Settings → Account → API Tokens**.
2. Find the token in the list and click **Revoke**.
3. The token stops working immediately. Any request using this token receives an HTTP 401 Unauthorized response.

When an administrator removes a member from a workspace, Octarq automatically revokes all API tokens created by that member in the workspace.
