The AI Workforce page runs the agents of the workspace and their task tickets.

A new workspace starts empty. The page shows the agents and tickets stored in the workspace.

## AI Employees

**AI Workforce → AI Employees** lists the agents of the workspace.

Deploy an agent with **Deploy AI Employee**. A name, a role, a department, a model, and a monthly budget limit are required. The budget limit must be greater than zero.

An agent has one of these states:

- **Active**: The agent accepts new tickets.
- **Idle**: The agent has no work in progress.
- **Paused**: The agent is out of service. Its tickets stay assigned.
- **Executing**: The agent reports activity now.

Use **Pause** to stop an agent. Use **Resume** to return it to service. Use **Heartbeat** to record that the agent is executing now.

An agent that still owns tickets cannot be deleted. Reassign or delete those tickets first.

## Tasks & Issues

**AI Workforce → Tasks & Issues** lists the task tickets.

Create a ticket with **Assign Task**. Select an agent, select a priority, and write the objective. The objective is required.

A ticket moves through these states:

1. **To do**: The ticket waits for the agent.
2. **In progress**: The agent works on the ticket.
3. **Awaiting approval**: The ticket needs an operator decision.
4. **Done**: The ticket is complete.

A ticket cannot move from **To do** straight to **Done**. Start the work first.

**Done** is final. A finished ticket cannot return to an earlier state.

Every ticket keeps its execution log. Open a ticket to read the log.

## Board Approvals

**AI Workforce → Board Approvals** lists the tickets that wait for a decision.

Approve a ticket to resume the work. Reject a ticket to return it to **To do**, so the agent can revise it.

A decision applies once. A ticket that is not awaiting approval cannot receive a decision.

## Budgets & Governance

**AI Workforce → Budgets & Governance** shows the spending of the workspace.

- **Workspace Monthly Spend** is the total of every agent.
- The limit is the total of the agent budget limits.
- **Spend Breakdown by Agent** shows the share of each agent.
- **Spend Breakdown by LLM Provider** shows the share of each provider.

The platform bills each agent turn at the price of the model in that turn.

### Model Prices

**Model Prices** sets the cost of each model that agents use.

The platform bills an agent turn at the price of its model. The platform refuses a turn on a model without a price. Add the price before you call the model.

Use **Save Price** to add or replace a price. Enter the model identifier that the provider uses. Enter the input price and the output price per one million tokens. A price of zero marks a model with no token cost.

Use **Delete price** to remove a price.

### Spend and Limits

Each agent counts its spend for the current calendar month. The counter starts again at the beginning of a month in UTC.

**Runaway Spend Guard (Fail-Closed)** decides whether the limit stops an agent.

- When the switch is on, an agent pauses at the limit. A paused agent does not run a turn.
- When the switch is off, spend is recorded and shown, but the limit stops nothing.

Raise the budget limit to continue work after a stop. Then resume the agent.

### Recent Spend

**Recent Spend** lists each billed turn of the selected agent.

Each row shows the time, the model, the token counts, the source, and the charge. The newest turn comes first.

Select an agent to read its ledger.

The ledger is the record behind the budget counter. A turn that is missing from the ledger was not charged.

### Bill a Chat Turn to an Agent

A workspace admin can charge chat turns to an agent.

1. Press ⌘J to open **AI Copilot**.
2. Select the agent in **Bill to**.
3. Send the turn.

The selector shows the agent spend beside the agent name.

Select **No agent** to run turns without a charge.

The platform refuses an attributed turn in four cases:

- The agent is paused. Resume the agent first.
- The agent reached its limit and the guard is on. Raise the limit first.
- The model has no price. Add the price first.
- A member starts the turn. Only an admin can bill a turn.

## Access Permissions

The AI Workforce page needs the workspace admin role.

Members without the admin role cannot open the page.
