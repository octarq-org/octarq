Octarq API 令牌支持在无需共享账户密码的情况下，为自动化脚本、CI/CD 流水线以及远程 Agent 提供安全的调用凭证。每个令牌均限定在当前工作区内，并受创建者的角色权限约束。

## 创建 API 令牌

1. 前往 **设置 → 账户 → API 令牌**（或按 `⌘K` / `Ctrl+K` 搜索“API 令牌”）。
2. 点击 **新建令牌**。
3. 配置令牌选项：
   - **名称**：输入描述性名称，例如 `GitHub Actions` 或 `发布脚本`。
   - **角色**：选择 `Member`、`Admin` 或 `Owner`。你无法授予高于自身工作区角色的权限。
   - **过期时间**：选择 7、30、90 天，或留空生成永久令牌。
   - **备注**：（可选）添加令牌使用场景说明。
4. 点击 **创建令牌**。
5. 立即复制显示的明文令牌。Octarq 对令牌进行加密存储，后续不再展示明文。

## 选择角色权限范围

每个 API 令牌均受工作区角色访问控制 (RBAC) 约束：

- **Member**：常规操作权限，可创建和管理短链、邮箱与域名记录。
- **Admin**：包含常规操作，并可管理工作区设置、DNS 服务商、Webhook 端点与告警。
- **Owner**：工作区全部权限，包括成员邀请、账单与工作区注销。

:::note 权限上限约束
你只能签发权限等于或低于自身工作区角色的令牌。如果你是 Admin，则无法创建 Owner 权限的令牌。
:::

## 发送认证请求

发起 API 请求时，在 HTTP `Authorization` 请求头中传入附带 `Bearer` 前缀的令牌：

```http
Authorization: Bearer oct_your_secret_api_token
```

### 查询域名列表

```bash
curl -s -X GET "https://your-octarq-host.com/api/domains" \
  -H "Authorization: Bearer oct_your_secret_api_token" \
  -H "Accept: application/json"
```

### 创建短链接

```bash
curl -s -X POST "https://your-octarq-host.com/api/links" \
  -H "Authorization: Bearer oct_your_secret_api_token" \
  -H "Content-Type: application/json" \
  -d '{
    "target": "https://example.com/docs",
    "slug": "docs"
  }'
```

## 吊销 API 令牌

1. 前往 **设置 → 账户 → API 令牌**。
2. 在列表中找到对应令牌，点击 **吊销**。
3. 令牌立即失效。后续使用该令牌发起的请求均会返回 HTTP 401 错误。

当管理员从工作区中移除成员时，Octarq 会自动吊销该成员在该工作区创建的所有 API 令牌。
