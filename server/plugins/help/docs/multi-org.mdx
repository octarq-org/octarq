Octarq is built on multi-tenancy. Every domain, mailbox, short link, API token, Webhook, and audit record belongs to a specific workspace (organization). Workspaces provide secure administrative boundaries so teams and projects operate independently on a single deployment.

## Understand Workspace Isolation

Workspaces keep your data strictly separated:

- **Data isolation**: Every domain, mailbox, link, API token, and Webhook belongs to a specific workspace. Switching workspaces filters all dashboard views and API queries to that organization.
- **Dedicated subdomains**: Workspaces can use dedicated automatic subdomains protected from base domain conflicts.
- **Member access**: Members can only see resources within workspaces where they belong.

## Understand Member Roles

Octarq provides three standard workspace roles:

| Capability / Action | Member | Admin | Owner |
|---|---|---|---|
| View links, mailboxes, and domains | Yes | Yes | Yes |
| Create and edit links, mailboxes, and domains | Yes | Yes | Yes |
| Export analytics and CSV reports | Yes | Yes | Yes |
| Manage outbound SMTP senders and suppressions | No | Yes | Yes |
| Configure Webhooks and alerts | No | Yes | Yes |
| Connect DNS provider accounts | No | Yes | Yes |
| Invite members and manage Member roles | No | Yes | Yes |
| Promote or demote Admin members | No | No | Yes |
| Manage billing and workspace settings | No | No | Yes |
| Transfer ownership or delete workspace | No | No | Yes |

## Switch Your Workspace

1. Click the workspace menu at the top of the left sidebar.
2. Select an organization from the list.
3. The dashboard reloads immediately with the selected workspace's data.

## Create a Workspace

1. Click the workspace menu at the top of the left sidebar.
2. Click **Create Workspace**.
3. Enter an organization name (such as `Acme Global`).
4. Click **Create & Switch**. You become the Owner of the new workspace.

## Invite Team Members

1. Go to **Settings → Workspace → Members** (or press `⌘K` / `Ctrl+K` and search "Members").
2. Click **Invite Member**.
3. Enter the member's email address and select an initial role (**Member**, **Admin**, or **Owner**).
4. Click **Send Invite**. Octarq sends an email with an invitation link valid for 24 hours.
5. If the invite expires before the recipient accepts, click **Resend Invite** from the members list.

## Manage Ownership and Departures

- **Maintain at least one Owner**: Every organization must have at least one active Owner. You cannot remove or demote the last remaining Owner.
- **Transfer ownership**: To transfer ownership, invite or promote another member to Owner first. Once multiple Owners exist, the previous Owner can step down safely.
- **Remove a member**: When you remove a member from a workspace, their access ends immediately. All API tokens created by that member in this workspace are revoked automatically.
