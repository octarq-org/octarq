Octarq Outbound Webhooks stream real-time JSON event payloads to your external application servers whenever activities occur in your workspace. This enables automation for CRM pipelines, custom alerts, event logging, and serverless edge functions.

## Subscribe to Events

When creating a webhook, choose specific events or subscribe to `*` for all workspace events:

- `email.receive`: Dispatched when an inbound email is received and stored.
- `email.send_failed`: Dispatched when an outbound email fails or bounces.
- `domain.verify_failed`: Dispatched when DNS verification detects a problem with SPF, DMARC, or DKIM records.
- `link.click_limit`: Dispatched when a short link reaches its click limit.
- `abuse.report`: Dispatched when an abuse report is submitted.

## Verify Webhook Signatures

Octarq sends HTTP POST requests with JSON payloads and delivery headers:

| Header | Description | Example |
|---|---|---|
| `Content-Type` | Payload format | `application/json` |
| `User-Agent` | Client identifier | `Octarq-Webhook/1.0` |
| `X-Octarq-Delivery` | Unique UUID for this delivery attempt | `7b8f9e12-4c3a-4e89-a123-d8e7f6a5b4c3` |
| `X-Octarq-Timestamp` | Unix timestamp in seconds | `1725801600` |
| `X-Octarq-Attempt` | Attempt counter | `1` |
| `X-Octarq-Signature` | Legacy V1 HMAC-SHA256 signature | `sha256=a1b2c3d4e5...` |
| `X-Octarq-Signature-V2` | Hardened V2 signature binding timestamp, delivery ID, and body | `v2=f6e5d4c3b2...` |

To verify signatures and protect against replay attacks on your receiver:

1. Check the timestamp: Read `X-Octarq-Timestamp` and reject requests older than 5 minutes (`300` seconds) to prevent replay attacks.
2. Deduplicate deliveries: Check `X-Octarq-Delivery` against recently seen IDs to avoid processing duplicate events.
3. Compute signature: Hash `<X-Octarq-Timestamp>.<X-Octarq-Delivery>.<raw_body>` using HMAC-SHA256 with your signing secret.
4. Compare signatures: Use constant-time string comparison to compare your calculated signature with `X-Octarq-Signature-V2`.

## Verification Code Examples

### Node.js (Express)

```javascript
const crypto = require('crypto');

function verifyOctarqWebhook(req, res, next) {
  const timestamp = req.headers['x-octarq-timestamp'];
  const deliveryId = req.headers['x-octarq-delivery'];
  const sigHeader = req.headers['x-octarq-signature-v2'];
  const secret = process.env.OCTARQ_WEBHOOK_SECRET;

  if (!timestamp || !deliveryId || !sigHeader) {
    return res.status(401).send('Missing webhook signature headers');
  }

  // 1. Verify 5-minute replay tolerance window
  const now = Math.floor(Date.now() / 1000);
  if (Math.abs(now - parseInt(timestamp, 10)) > 300) {
    return res.status(401).send('Timestamp out of tolerance window');
  }

  // 2. Compute expected V2 HMAC
  const signedMaterial = `${timestamp}.${deliveryId}.${req.rawBody}`;
  const expectedHash = crypto
    .createHmac('sha256', secret)
    .update(signedMaterial)
    .digest('hex');
  const expectedSignature = `v2=${expectedHash}`;

  // 3. Constant-time equality check
  const trusted = Buffer.from(expectedSignature, 'utf8');
  const untrusted = Buffer.from(sigHeader, 'utf8');
  if (trusted.length === untrusted.length && crypto.timingSafeEqual(trusted, untrusted)) {
    return next();
  }

  return res.status(401).send('Invalid signature');
}
```

### Python (FastAPI)

```python
import hmac
import hashlib
import time
from fastapi import FastAPI, Header, HTTPException, Request

app = FastAPI()
WEBHOOK_SECRET = "your_signing_secret"

@app.post("/webhook/octarq")
async def handle_webhook(
    request: Request,
    x_octarq_timestamp: str = Header(...),
    x_octarq_delivery: str = Header(...),
    x_octarq_signature_v2: str = Header(...)
):
    body = await request.body()
    
    # 1. Verify 5-minute replay tolerance window
    now = int(time.time())
    if abs(now - int(x_octarq_timestamp)) > 300:
        raise HTTPException(status_code=401, detail="Timestamp expired")
        
    # 2. Compute expected V2 HMAC
    signed_material = f"{x_octarq_timestamp}.{x_octarq_delivery}.".encode('utf-8') + body
    expected_hash = hmac.new(
        WEBHOOK_SECRET.encode('utf-8'),
        signed_material,
        hashlib.sha256
    ).hexdigest()
    expected_sig = f"v2={expected_hash}"
    
    # 3. Constant-time comparison
    if not hmac.compare_digest(expected_sig, x_octarq_signature_v2):
        raise HTTPException(status_code=401, detail="Signature mismatch")
        
    payload = await request.json()
    return {"status": "ok"}
```

### Go (net/http)

```go
package main

import (
	"crypto/hmac"
	"crypto/sha256"
	"crypto/subtle"
	"encoding/hex"
	"fmt"
	"io"
	"math"
	"net/http"
	"strconv"
	"time"
)

func verifyWebhook(w http.ResponseWriter, r *http.Request, secret []byte) ([]byte, error) {
	tsStr := r.Header.Get("X-Octarq-Timestamp")
	deliveryID := r.Header.Get("X-Octarq-Delivery")
	sigHeader := r.Header.Get("X-Octarq-Signature-V2")

	ts, err := strconv.ParseInt(tsStr, 10, 64)
	if err != nil || math.Abs(float64(time.Now().Unix()-ts)) > 300 {
		return nil, fmt.Errorf("invalid or expired timestamp")
	}

	body, err := io.ReadAll(r.Body)
	if err != nil {
		return nil, err
	}

	mac := hmac.New(sha256.New, secret)
	mac.Write([]byte(tsStr + "." + deliveryID + "."))
	mac.Write(body)
	expectedSig := "v2=" + hex.EncodeToString(mac.Sum(nil))

	if subtle.ConstantTimeCompare([]byte(expectedSig), []byte(sigHeader)) != 1 {
		return nil, fmt.Errorf("signature verification failed")
	}
	return body, nil
}
```

## Create a Webhook Endpoint

1. Go to **Settings → Workspace → Webhooks** (or press `⌘K` / `Ctrl+K` and search "Webhooks").
2. Click **Add Webhook Endpoint**.
3. Configure endpoint settings:
   - **Name**: Enter a descriptive label (such as `Event Consumer`).
   - **Endpoint URL**: Enter your HTTPS target destination (such as `https://api.example.com/webhooks/octarq`).
   - **Signing Secret**: Enter your own secret or leave blank to let Octarq generate one.
   - **Events**: Select specific event topics or subscribe to all events (`*`).
4. Click **Create Endpoint**.
