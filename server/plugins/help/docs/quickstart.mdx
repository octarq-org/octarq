Get an Octarq instance running with Docker in less than five minutes. Octarq ships as a unified container bundling an embedded database, front-end assets, and background workers.

## Launch the Docker Container

1. Run the container command on your server or local machine:
   ```bash
   docker run -d \
     --name octarq \
     -p 8080:8080 \
     -v octarq_data:/app/data \
     -e OCTARQ_APP_NAME="Production Studio" \
     --restart unless-stopped \
     ghcr.io/octarq-org/octarq:latest
   ```
2. Configure environment variables as needed:

   | Variable | Default | Description |
   |---|---|---|
   | `OCTARQ_PORT` | `8080` | HTTP port inside the container |
   | `OCTARQ_DATA_DIR` | `/app/data` | Storage path for database and uploads |
   | `OCTARQ_APP_NAME` | `Octarq` | Brand name shown on login and navigation |
   | `OCTARQ_BASE_DOMAIN` | *(optional)* | Base domain for automatic subdomains |

3. Open `http://localhost:8080` (or `http://your-server-ip:8080`) in your browser to begin setup.

## Set Up Admin Account and Workspace

1. Enter your email and a password. The first registered user automatically becomes the Instance Admin.
2. Enter an organization name (such as `Acme Corp`) to create your first workspace.
3. Click **Complete Setup** to open the dashboard as the workspace Owner.
4. Invite other team members later under **Settings → Workspace → Members**.

## Add Feature Plugins

Octarq core ships the platform only. Install plugins to add features.

1. Use an official plugin from the octarq-plugins repository, or use Octarq Pro.
2. Restart the server after you add a backend plugin to the build.
3. Enable the feature in **Settings → Workspace → Features**.

Feature plugins add their own help pages to this help center.

## Turn On Workspace Features

1. Go to **Settings → Workspace → Features** (or press `⌘K` / `Ctrl+K` and search "Features").
2. Turn on the installed plugins your team needs.
3. The left sidebar updates immediately.
