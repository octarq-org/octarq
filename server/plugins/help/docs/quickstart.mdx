Get an Octarq instance running in less than five minutes. Octarq runs as one container that bundles an embedded database, the dashboard and the background workers.

## Build and Start Octarq

Octarq publishes no container image. A useful build carries the plugins you pick, so you build the image from your own source tree.

1. Clone the source and build the image:
   ```bash
   git clone https://github.com/octarq-org/octarq && cd octarq
   docker compose up -d --build
   ```
2. Set these variables in `.env` when you manage them yourself:

   | Variable | Default | Description |
   |---|---|---|
   | `OCTARQ_LISTEN` | `:8080` | HTTP listen address |
   | `OCTARQ_DB_DRIVER` | `sqlite` | Database driver: `sqlite`, `postgres` or `mysql` |
   | `OCTARQ_DB_DSN` | `octarq.db` | Database connection string |
   | `OCTARQ_STORAGE_DIR` | `./data/storage` | Directory for uploaded files |
   | `OCTARQ_SECRET_KEY` | *(generated)* | Leave empty to generate a key on first boot |
   | `OCTARQ_ADMIN_USER` | `admin` | Administrator user name |
   | `OCTARQ_ADMIN_PASSWORD` | *(generated)* | Leave empty to generate a password on first boot |

3. Read the generated administrator password:
   ```bash
   docker compose cp octarq:/data/octarq-admin-password.txt .
   cat octarq-admin-password.txt
   ```
4. Open `http://localhost:8080` in your browser to begin setup.

## Set Up Admin Account and Workspace

1. Enter your email and a password. The first registered user automatically becomes the Instance Admin.
2. Enter an organization name (such as `Acme Corp`) to create your first workspace.
3. Click **Complete Setup** to open the dashboard as the workspace Owner.
4. Invite other team members later under **Settings → Workspace → Members**.

## Add Feature Plugins

Octarq core ships the platform only. Install plugins to add features.

1. Use an official plugin from the octarq-plugins repository, or use Octarq Pro.
2. Restart the server after you add a backend plugin to the build.
3. Enable the feature in **Settings → Workspace → Features**.

Feature plugins add their own help pages to this help center.

## Turn On Workspace Features

1. Go to **Settings → Workspace → Features** (or press `⌘K` / `Ctrl+K` and search "Features").
2. Turn on the installed plugins your team needs.
3. The left sidebar updates immediately.
