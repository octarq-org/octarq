Get an Octarq instance running with Docker in less than five minutes. Octarq ships as a unified, single-binary container bundling an embedded SQLite database, front-end assets, and background workers.

## Step 1: Launch the Docker Container

Run the following command on your server or local environment:

```bash
docker run -d \
  --name octarq \
  -p 8080:8080 \
  -v octarq_data:/app/data \
  -e OCTARQ_APP_NAME="Production Studio" \
  --restart unless-stopped \
  ghcr.io/octarq-org/octarq:latest
```

### Environment Variables

| Variable | Default | Description |
|---|---|---|
| `OCTARQ_PORT` | `8080` | HTTP port the server listens on inside the container. |
| `OCTARQ_DATA_DIR` | `/app/data` | Path to persistent storage volume housing the database and uploads. |
| `OCTARQ_APP_NAME` | `Octarq` | Brand name displayed on the login page and navigation header. |
| `OCTARQ_BASE_DOMAIN` | *(optional)* | Base domain used for automatic multi-tenant subdomain routing. |

Open `http://localhost:8080` (or `http://your-server-ip:8080`) in your browser to access the setup wizard.

## Step 2: Register Instance Admin and Workspace

1. **Initial Admin Setup**:
   - The first user to register on a fresh instance becomes the **Instance Admin**.
   - Enter your email address and a strong password.
2. **First Workspace**:
   - Enter your organization or project name (e.g. `Acme Corp`).
   - Octarq provisions your first workspace with you designated as the **Owner**.
3. Team members can be invited later under **Settings → Workspace → Members**.

## Step 3: Connect and Bind Custom Domains

To use branded short links or receive domain email, connect your DNS zone:

1. Configure an `A` record (or `CNAME` record) in your public DNS provider pointing your domain or subdomain to your Octarq server IP.
2. In Octarq, navigate to **Infrastructure → Network → DNS** (refer to [DNS Management](/help/dns)).
3. Click **+ Add Domain Zone** to register your domain manually, or click the **Provider Accounts** tab to bind a Cloudflare or DNSPod API token and click **Sync Domains** for automated synchronization.

## Step 4: Toggle Workspace Features

Customize the active workspace interface:

1. Navigate to **Settings → Workspace → Features** (or use the command palette `⌘K` and search "Features").
2. Toggle on the capabilities your team intends to use:
   - **Links**: Create branded short links, conditional routing, and A/B split testing.
   - **Mail**: Ingest incoming email webhooks and dispatch transactional notifications.
   - **DNS**: Orchestrate resource records and dynamic DNS tokens.
3. Left-hand navigation menus adapt dynamically to your active feature set.
