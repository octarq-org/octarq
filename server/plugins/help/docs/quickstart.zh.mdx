只需不到五分钟，即可通过 Docker 快速启动一套生产就绪的 Octarq 实例。Octarq 采用一体化容器打包，内置嵌入式数据库、Web 控制台资源与后台异步任务调度器。

## 启动 Docker 容器

1. 在服务器或本地终端执行容器启动命令：
   ```bash
   docker run -d \
     --name octarq \
     -p 8080:8080 \
     -v octarq_data:/app/data \
     -e OCTARQ_APP_NAME="生产环境控制台" \
     --restart unless-stopped \
     ghcr.io/octarq-org/octarq:latest
   ```
2. 按需配置环境变量：

   | 环境变量 | 默认值 | 作用描述 |
   |---|---|---|
   | `OCTARQ_PORT` | `8080` | 容器内部服务监听的 HTTP 端口 |
   | `OCTARQ_DATA_DIR` | `/app/data` | 持久化数据挂载卷路径，存放数据库及上传文件 |
   | `OCTARQ_APP_NAME` | `Octarq` | 登录页面与顶部导航展示的品牌名称 |
   | `OCTARQ_BASE_DOMAIN` | *(可选)* | 平台共享基础域名，用于生成自动化租户多级子域名 |

3. 在浏览器中打开 `http://localhost:8080`（或 `http://服务器IP:8080`）开始初始化向导。

## 创建管理员账号与首个工作区

1. 输入管理员邮箱和密码。系统首次部署注册的首位用户自动成为实例管理员。
2. 输入组织名称（例如 `Acme Corp`）以创建首个工作区。
3. 点击 **完成初始化** 进入控制台，你将自动成为该工作区的 Owner。
4. 随后可在 **设置 → 工作区 → 成员** 中邀请其他团队成员。

## 绑定自定义域名

1. 在 DNS 服务商处添加 `A` 记录或 `CNAME` 记录，将域名解析至 Octarq 服务器。
2. 进入 Octarq 的 **基础设施 → 网络 → DNS**（参见 [DNS 域名解析](/help/dns)）。
3. 点击 **添加域名 Zone** 手动添加域名，或进入 **服务商账户** 绑定 Cloudflare 或 DNSPod 并点击 **同步域名**。

## 开启工作区功能

1. 进入 **设置 → 工作区 → 功能**（或按 `⌘K` / `Ctrl+K` 搜索“功能”）。
2. 勾选团队需要使用的业务模块：
   - **短链 (Links)**：创建短链接、访客分流规则与 A/B 分流测试。
   - **邮件 (Mail)**：接收入站邮件 Webhook 并配置路由。
   - **域名解析 (DNS)**：管理域名解析记录与动态 DNS 令牌。
3. 左侧边栏菜单会立即刷新并展示已启用的功能模块。
