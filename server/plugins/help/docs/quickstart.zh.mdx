只需不到五分钟，即可启动一套 Octarq 实例。Octarq 以单个容器运行，内置数据库、Web 控制台与后台异步任务调度器。

## 构建并启动 Octarq

Octarq 不发布容器镜像。有用的构建要带上你选的插件，所以镜像由你自己从源码树构建。

1. 克隆源码并构建镜像：
   ```bash
   git clone https://github.com/octarq-org/octarq && cd octarq
   docker compose up -d --build
   ```
2. 想自己管理时，在 `.env` 中设置这些变量：

   | 环境变量 | 默认值 | 作用描述 |
   |---|---|---|
   | `OCTARQ_LISTEN` | `:8080` | HTTP 监听地址 |
   | `OCTARQ_DB_DRIVER` | `sqlite` | 数据库驱动：`sqlite`、`postgres` 或 `mysql` |
   | `OCTARQ_DB_DSN` | `octarq.db` | 数据库连接串 |
   | `OCTARQ_STORAGE_DIR` | `./data/storage` | 上传文件存放目录 |
   | `OCTARQ_SECRET_KEY` | *(自动生成)* | 留空则首次启动时生成密钥 |
   | `OCTARQ_ADMIN_USER` | `admin` | 管理员用户名 |
   | `OCTARQ_ADMIN_PASSWORD` | *(自动生成)* | 留空则首次启动时生成密码 |

3. 取出自动生成的管理员密码：
   ```bash
   docker compose cp octarq:/data/octarq-admin-password.txt .
   cat octarq-admin-password.txt
   ```
4. 在浏览器中打开 `http://localhost:8080` 开始初始化。

## 创建管理员账号与首个工作区

1. 输入管理员邮箱和密码。系统首次部署注册的首位用户自动成为实例管理员。
2. 输入组织名称（例如 `Acme Corp`）以创建首个工作区。
3. 点击 **完成初始化** 进入控制台，你将自动成为该工作区的 Owner。
4. 随后可在 **设置 → 工作区 → 成员** 中邀请其他团队成员。

## 添加功能插件

Octarq 核心仅提供平台能力。安装插件即可添加业务功能。

1. 使用 octarq-plugins 仓库中的官方插件，或使用 Octarq Pro。
2. 将后端插件加入构建后，重启服务器。
3. 在 **设置 → 工作区 → 功能** 中启用该功能。

功能插件会将自己的帮助页面添加到本帮助中心。

## 开启工作区功能

1. 进入 **设置 → 工作区 → 功能**（或按 `⌘K` / `Ctrl+K` 搜索“功能”）。
2. 开启团队所需的已安装插件。
3. 左侧边栏菜单会立即刷新。
