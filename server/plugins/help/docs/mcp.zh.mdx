Octarq 内置标准模型上下文协议 (Model Context Protocol, MCP) 服务端，允许大语言模型 (LLM)、IDE 编程助手及自动化 Agent 安全调用工具，管理工作区内的短链、邮件与 DNS 记录。

## 选择连接方式

Octarq 提供两种标准连接方式：

- **本地 stdio 连接**：适用于在本地运行的桌面助手（如 Claude Desktop 和 Cursor）。直接通过 `octarq mcp` 启动。
- **远程 HTTP 与 SSE 连接**：适用于云端 AI Agent 与外部系统。通过 [API 令牌](/help/api-tokens)（`Authorization: Bearer oct_...`）连接到 `https://your-octarq-host.com/api/mcp/sse`。所有操作严格限定在令牌对应的工作区内。

:::note 结构化工具调用
Octarq 提供安全的结构化工具调用，不暴露底层原始 SQL 查询。这能确保多租户数据隔离，防止越权访问。
:::

## 可用工具列表

无论通过 stdio 还是 SSE 连接，MCP 服务端均提供以下标准工具：

- **`create_shortlink`**：创建短链接，支持设置目标落地页、自定义别名、域名、访问密码和过期时间。
- **`list_links`**：分页查询当前工作区下的短链接列表，支持限制条数与关键词检索。
- **`list_domains`**：查看已绑定的域名与 DNS 验证状态（SPF、DKIM、DMARC）。
- **`list_mailboxes`**：查看邮箱列表、地址与未读邮件计数。
- **`list_emails`**：查看最近收到的事务邮件列表，包含发件人、主题和摘要。
- **`get_latest_otp`**：从最近 10 分钟内收到的未读邮件中提取验证码 (OTP)。
- **`get_email_summary`**：获取邮件的脱敏摘要，自动识别类别与验证码。
- **`get_email_content`**：获取脱敏后的邮件纯文本正文，自动移除敏感链接。
- **`export_data`**：导出工作区数据（短链、邮件、域名或邮箱）的 JSON 记录。

## 读取监控资源

AI 客户端可以读取工作区监控资源：

- **`octarq://metrics/traffic`**：当前工作区的短链跳转与点击量统计。
- **`octarq://domains/health`**：已绑定域名的 DNS 配置与健康状态。

## 配置 Claude Desktop

1. 打开 Claude Desktop 配置文件（macOS 位于 `~/Library/Application Support/Claude/claude_desktop_config.json`，Windows 位于 `%APPDATA%\Claude\claude_desktop_config.json`）。
2. 添加 `octarq` 服务配置：
   ```json
   {
     "mcpServers": {
       "octarq": {
         "command": "/usr/local/bin/octarq",
         "args": ["mcp"],
         "env": {
           "OCTARQ_DB_DSN": "/var/lib/octarq/data.db"
         }
       }
     }
   }
   ```
3. 重启 Claude Desktop。

## 配置 Cursor

1. 在项目根目录中创建或编辑 `.cursor/mcp.json`。
2. 添加远程 Octarq 连接配置：
   ```json
   {
     "mcpServers": {
       "octarq-remote": {
         "url": "https://your-octarq-host.com/api/mcp/sse",
         "headers": {
           "Authorization": "Bearer oct_your_secret_api_token"
         }
       }
     }
   }
   ```
3. 保存文件并重启 Cursor。

## 使用自然语言提示词

配置完成后，你可以直接在聊天框中使用自然语言向 AI 助手发出指令：

- “在域名 go.example.com 上创建一个指向 https://example.com/docs 的短链，别名设为 docs”
- “检查当前工作区所有域名的验证状态”
- “查找客服邮箱最近 5 分钟内收到的验证码”
