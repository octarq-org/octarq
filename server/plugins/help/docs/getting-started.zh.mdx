Octarq 管理控制台为开发者与运营团队提供了一体化、直观高效的操作界面，集中管理品牌短链、事务邮件收发、DNS 域名解析、API 调用凭证以及多租户团队协作。本指南将带您快速熟悉控制台核心布局、快捷键操作及功能配置。

## 工作区控制台布局与导航

管理后台界面分为三大核心功能区域：

1. **顶部与工作区选择器**：
   - 位于左侧边栏顶部。
   - 实时显示当前处于激活状态的组织工作区。点击可即时在个人工作区与多个企业组织之间自由切换，或一键创建新工作区。
2. **模块化侧边栏导航**：
   - **日常运营 (Operations)**：涵盖日常营销与通信工具，包括 [短链](/help/short-links) 与 [邮箱与邮件路由](/help/mailboxes)。
   - **基础设施 (Infrastructure)**：底层网络与解析管理，包括 [DNS 域名解析](/help/dns) 与 [动态 DNS (DDNS)](/help/ddns)。
   - **全局设置 (Settings)**：工作区系统设置、[API 令牌](/help/api-tokens)、[告警通知渠道](/help/notifications) 及 [出站 Webhook](/help/webhooks)。
3. **主内容工作视窗**：
   - 承载高密度的业务数据表格、实时分析可视化看板、配置抽屉侧栏及内置帮助文档。

## 全局命令面板 (`⌘K` / `Ctrl+K`)

使用内置的全局命令面板大幅提升高频操作效率：

- **快速唤起**：在控制台任意界面按下 **`⌘K`** (macOS) 或 **`Ctrl+K`** (Windows/Linux) 即可打开命令面板。
- **全局即时检索**：输入关键字（如 "DNS"、"Token"、"导出"）即可直达对应业务页面、系统设置项或技术文档。
- **操作安全性**：命令面板专为快速检索与界面导航优化，不会直接执行任何破坏性操作，修改或删除数据前仍需通过二次确认抽屉。
- **退出面板**：按 `Esc` 键即可关闭面板返回先前视图。

## 多租户数据隔离边界

Octarq 严格遵循多租户数据隔离原则：
- 切换当前工作区后，所有可见的短链、邮件、DNS 解析记录及审计日志将实时切换并严格过滤为当前选中的租户。
- 未获得当前工作区授权的用户无法查看其任何数据，也无法通过枚举 ID 获取信息。
- 更多关于团队邀请、角色权限矩阵及所有权转让的说明，请参考 [组织与团队权限](/help/multi-org)。

## 按工作区动态开启或隐藏功能

管理员可根据具体业务场景，灵活定制各个组织工作区的功能菜单：

1. 前往 **设置 → 工作区 → 功能**（或直接访问 `/settings/plugins`）。
2. 根据团队需求勾选或关闭特定功能（如短链、邮件、DNS 解析等）。
3. 未启用的功能模块在侧边栏中将自动隐藏，精简视觉层级，但已有的底层数据库记录不会被删除。
