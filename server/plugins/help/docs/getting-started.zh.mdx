Octarq 管理控制台提供了一体化的操作界面，集中管理短链、事务邮件、DNS 解析、API 令牌以及多租户团队协作。本指南介绍控制台核心布局、快捷键操作、工作区隔离机制与功能配置。

## 熟悉控制台布局

控制台界面分为三大主要功能区域：

1. **工作区切换器**：位于左侧边栏顶部，显示当前处于活跃状态的工作区。点击可切换组织或创建新工作区。
2. **侧边栏导航**：
   - **日常运营**：日常短链与邮件工具，包括 [短链](/help/short-links) 与 [邮箱](/help/mailboxes)。
   - **基础设施**：网络与域名工具，包括 [DNS 域名解析](/help/dns) 与 [动态 DNS (DDNS)](/help/ddns)。
   - **设置**：组织偏好设置、[API 令牌](/help/api-tokens)、[告警通知渠道](/help/notifications) 与 [出站 Webhook](/help/webhooks)。
3. **主工作视窗**：显示数据表格、数据指标、配置抽屉与帮助文档。

## 使用快捷键命令面板

使用键盘命令面板快速完成高频导航：

- **快速检索**：在任意界面按 `⌘K` (macOS) 或 `Ctrl+K` (Windows/Linux) 打开面板，输入 "DNS"、"Tokens" 或 "导出" 等关键字直达页面或文档。
- **快速跳转**：无需点击层级菜单即可直达目标模块与设置项。
- **关闭面板**：按 `Esc` 键退出搜索。

## 切换工作区

Octarq 严格遵循组织数据隔离机制：

- 切换当前工作区后，所有短链、邮箱、域名解析记录与审计日志均会自动按当前组织过滤。
- 未获得该工作区访问权限的团队成员无法查看其内部资源或枚举资源 ID。
- 如需了解成员邀请与角色权限，请查阅 [组织与团队权限](/help/multi-org)。

## 开启工作区功能

根据团队需求定制工作区侧边栏显示的功能模块：

1. 前往 **设置 → 工作区 → 功能**（或按 `⌘K` / `Ctrl+K` 搜索“功能”）。
2. 开启团队所需的功能模块（例如短链、邮件或 DNS 解析）。
3. 关闭暂不需要的功能以简化菜单。隐藏的项目不会影响数据库中已有的数据。
