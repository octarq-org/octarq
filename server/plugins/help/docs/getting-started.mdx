The Octarq management console provides an integrated interface to manage workspaces, API tokens, alerts, webhooks, and installed feature plugins. This guide introduces the core layout, keyboard shortcuts, workspace isolation, and feature controls.

## Explore the Console Layout

The dashboard layout is divided into three primary functional areas:

1. **Workspace switcher**: Located at the top of the left sidebar. Displays your active organization. Click to switch between workspaces or create a new one.
2. **Sidebar navigation**:
   - **Feature areas**: Each installed plugin adds its pages here, such as Operations or Infrastructure.
   - **Settings**: Organization preferences, [API Tokens](/help/api-tokens), [Alerts](/help/notifications), and [Outbound Webhooks](/help/webhooks).
3. **Main workspace viewport**: Displays data tables, analytics, configuration drawers, and documentation.

## Use the Command Palette

Accelerate routine navigation using the keyboard command palette:

- **Search**: Press `⌘K` on macOS or `Ctrl+K` on Windows/Linux from any screen, then type keywords like "DNS", "Tokens", or "Export" to jump to pages or documentation.
- **Navigate**: Move across modules and settings without clicking through menus.
- **Exit**: Press `Esc` to close the palette.

## Switch Between Workspaces

Octarq enforces strict organization boundaries:

- Switching the active workspace filters all workspace records and audit events to the selected organization.
- Team members without access to a workspace cannot view its records or enumerate resource IDs.
- For member invitations and role permissions, see the [Organizations & Workspace RBAC](/help/multi-org) guide.

## Enable Workspace Features

Customize which features appear in your workspace sidebar:

1. Go to **Settings → Workspace → Features** (or press `⌘K` / `Ctrl+K` and search "Features").
2. Turn on the installed plugins that your workspace needs.
3. Turn off unused features to simplify navigation. Unused items disappear from the sidebar without deleting stored data.
