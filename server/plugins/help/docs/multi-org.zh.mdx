Octarq 基于多租户架构设计。所有域名、邮箱、短链、API 令牌、出站 Webhook 与审计记录均归属于特定的工作区（组织）。工作区提供清晰的数据与权限边界，支持多团队与多项目在同一实例中安全独立运行。

## 了解工作区隔离机制

工作区保持各组织数据严格隔离：

- **数据隔离**：所有域名、邮箱、短链、API 令牌与 Webhook 均归属于特定工作区。切换工作区后，控制台页面与 API 查询均会自动按当前组织过滤。
- **独立子域**：每个工作区可使用独立的自动化子域名，并受平台基准域名保护。
- **成员访问**：团队成员仅能访问已加入工作区内部的业务资源。

## 了解成员角色权限

Octarq 提供三层标准的工作区角色：

| 业务操作 / 功能模块 | Member | Admin | Owner |
|---|---|---|---|
| 查看短链、邮箱与域名记录 | 是 | 是 | 是 |
| 创建与编辑短链、邮箱与域名记录 | 是 | 是 | 是 |
| 导出分析数据与 CSV 报表 | 是 | 是 | 是 |
| 管理出站 SMTP 发件服务与退信名单 | 否 | 是 | 是 |
| 配置 Webhook 与告警通知渠道 | 否 | 是 | 是 |
| 绑定并管理 DNS 服务商账户 | 否 | 是 | 是 |
| 邀请团队成员并分配 Member 角色 | 否 | 是 | 是 |
| 晋升或降级 Admin 管理员角色 | 否 | 否 | 是 |
| 管理账单与工作区系统设置 | 否 | 否 | 是 |
| 转让工作区所有权或注销工作区 | 否 | 否 | 是 |

## 切换当前工作区

1. 点击左侧边栏顶部的工作区菜单。
2. 在下拉列表中选择目标组织。
3. 控制台将立即切换并显示所选工作区的数据。

## 创建新工作区

1. 点击左侧边栏顶部的工作区菜单。
2. 点击 **创建工作区**。
3. 输入组织名称（例如 `Acme Global`）。
4. 点击 **创建并切换**。你将自动成为新工作区的 Owner。

## 邀请团队成员

1. 前往 **设置 → 工作区 → 成员**（或按 `⌘K` / `Ctrl+K` 搜索“成员”）。
2. 点击 **邀请成员**。
3. 输入被邀请人的邮箱地址并选择初始角色（**Member**、**Admin** 或 **Owner**）。
4. 点击 **发送邀请**。系统会发送一封包含邀请链接的邮件，有效期为 24 小时。
5. 如果邀请在被接受前过期，可在成员列表中点击 **重新发送**。

## 管理所有权与成员离职

- **保留至少一位 Owner**：每个工作区必须保留至少一位活跃的 Owner。无法移除或降级最后一位 Owner。
- **转让所有权**：如需转让所有权，请先将另一位成员设为 Owner。当存在多名 Owner 时，原 Owner 即可安全变更角色。
- **移除成员**：从工作区移除成员后，其访问权限将立即终止，该成员在此工作区创建的所有 API 令牌也会自动吊销。
