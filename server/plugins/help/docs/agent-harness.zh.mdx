智能体 Harness 定义工作区内智能体的运行约束。智能体的每一次请求均遵循当前生效的规范。

## 概述

智能体 Harness 为工作区内的智能体确立运行边界。每个工作区同一时刻只有一份生效的 Harness 版本。当工作区未激活任何自定义版本时，系统运行内置的默认规范。

管理员可在 **设置 → Agent Harness** 进入管理页面。

## 版本与草稿

管理员通过版本与草稿管理规范配置。

更新智能体规范包含以下阶段：

1. **暂存草稿**：创建新草稿以调整提示词、工具清单与步数上限。
2. **核对差异**：将草稿变更与当前生效版本进行比对。
3. **激活上线**：选定目标版本并立即作为线上规范生效。

激活新版本会自动将先前的生效版本归档。管理员可以在版本操作菜单中直接作废无用的草稿。作废操作为永久标记，不可撤销。

## 工具清单

工具清单限制智能体可调用的工具。

- **不限制工具**：保持清单为空，允许智能体调用当前会话允许的全部工具。
- **自定义清单**：输入指定的工具名称以限制工具执行。

多个工具名称使用逗号或换行分隔。智能体只能执行清单中列出的工具。

## 步数上限

步数上限限制智能体单次请求发起的最大连续工具调用次数。

- 允许的步数范围为 1 至 8 步。
- 系统默认值为 6 步。

调小步数上限可防止智能体陷入死循环，并降低资源消耗。

## 附加规则

附加规则为智能体提示词追加自定义操作指令。

管理员可添加输出格式、响应语言或特定业务策略的规则。附加规则无法删除或绕过系统内置的安全指令。

## 经验账本

经验账本记录运维过程中沉淀的经验与提示词建议。

每条经验记录包含作用域、描述内容以及可选的 JSON 证据。经验包含三种生命周期状态：建议、已采纳和已忽略。

管理员可以在账本中忽略不需要的经验。已忽略的经验仍保留在账本中以供审计追溯。

单条经验记录本身不会改变智能体的行为。如需落实经验，请将其写入草稿规范并激活生效。

## 导入提案

管理员可以向工作区导入完整的 Harness 提案。

在导入弹窗中上传提案 JSON 文件或直接粘贴 JSON 文本。导入操作会生成一份新的暂存草稿。导入操作绝不会直接激活提案上线。

请在核对草稿差异后，按需手动激活该版本。

## 访问权限

管理智能体 Harness 需要工作区管理员权限。

非管理员成员无法编辑或激活 Harness 规范。普通成员打开此页面时将看到权限受限提示。请联系工作区管理员调整配置。

## 规范约束与限制

Harness 只能进一步收紧智能体的执行约束，无法突破平台底层权限。

- 无法授权当前会话本身未允许的工具。
- 无法将最大步数调整至 8 步以上。
- 无法删除平台内置的系统安全规则。
