Agent Harness 规定工作区智能体运行时的规则。每一次请求都使用当前生效的版本。

## 概述

每个工作区只有一份生效的 Harness 版本。从未激活过版本的工作区运行内置的默认规范。

**工作区 → Agent 运行环境** 打开管理页面。

## 版本与草稿

一个版本就是一份智能体规范。管理页面保留全部版本：生效的版本、草稿和历史版本。

更新智能体规范分三步：

1. **暂存草稿**：新建草稿，填写新的提示词、规则、工具清单和步数上限。
2. **核对差异**：将草稿与生效版本逐项比对。
3. **激活**：让核对过的版本生效。

激活一个版本会归档原先生效的版本。在版本操作菜单中作废草稿。作废的草稿无法恢复。

## 工具清单

工具清单列出智能体可以调用的工具。

- **清单为空**：智能体可以调用会话允许的全部工具。
- **清单列出名称**：智能体只能调用清单中的工具。

工具名称之间用逗号或换行分隔。

## 步数上限

步数上限限制智能体单次请求可发起的工具调用次数。

- 允许范围为 1 至 8 步。
- 编辑器默认填入 6 步。

调小上限可以避免智能体陷入循环，也能降低成本。

## 附加规则

附加规则为智能体提示词追加指令。

可以用它规定输出格式、响应语言或某个业务领域的规则。附加规则不能删除或绕过内置指令。

## 经验账本

经验账本记录工作区对智能体的观察。

每条经验包含作用域、说明和可选的 JSON 证据。一条经验处于建议、已采纳或已忽略三种状态。

不需要的经验可以忽略。已忽略的经验仍留在账本中备查。

经验本身不会改变智能体的行为。把经验写进草稿并激活该版本，它才会生效。

## 导入提案

把一份 Harness 提案导入工作区。

上传提案 JSON 文件，或把 JSON 粘贴到导入对话框。导入生成一份新草稿。导入不会激活提案。

核对草稿后，再激活该版本。

## 访问权限

管理 Agent Harness 需要工作区管理员角色。

没有管理员角色的成员会看到一条提示：此页面需要工作区管理员。

## 规范约束

Harness 只能收紧智能体的规则。

- 不能授权会话本身未允许的工具。
- 不能把步数上限设为 8 步以上。
- 不能删除内置指令。
