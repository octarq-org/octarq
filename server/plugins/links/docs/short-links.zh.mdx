Octarq 短链提供高吞吐的链接跳转与分流管理引擎。运营与增长团队可通过自定义域名创建品牌短链接、按访问者属性执行动态重定向、基于哈希算法开展确定性 A/B 测试、配置访问密码或点击阈值，并在严格保护访客隐私的前提下完成全链路渠道归因分析。

## 创建短链接

1. 进入 **日常运营 → 营销 → 短链**（或按 `⌘K` / `Ctrl+K` 搜索“短链”）。
2. 点击 **新建短链**。
3. 输入重定向的目标地址 **Target URL**（例如 `https://example.com/landing-page`）。
4. （可选）配置高级参数：
   - **Host（域名）**：选择当前工作区已绑定的自定义域名（例如 `go.example.com`）。未选择时将使用实例默认短链域名。
   - **自定义 Slug**：输入易记的路径别名（例如 `summer-sale`）。留空时系统将自动生成 6 位高强度随机字母数字 Slug。
5. 点击 **创建短链**。

### 自定义 Slug 与系统保留字校验

在指定自定义 Slug 时，系统执行严格的命名空间保护：

- **系统内置保留前缀**：内置路径包括 `/admin`、`/api`、`/assets`、`/portal`、`robots.txt` 与 `favicon.ico`，禁止用作短链 Slug，防止冲突。
- **全局保留关键字**：实例管理员在 **实例控制台 → 短链设置** 中配置的部署级保留字将直接返回 HTTP 409 Conflict。
- **Slug 唯一性校验**：同一域名 Host 下 Slug 必须保持唯一。若存在重复记录，创建请求将返回 HTTP 409 Conflict 报错。

## 自定义品牌域名与多租户隔离

绑定独立域名可显著提升点击转化率并维护品牌形象：

1. 在 [DNS 域名解析](/help/dns) 中绑定并验证您的自定义域名。
2. 创建或编辑短链时，在 **Host** 下拉菜单中选择该域名。
3. **多租户安全隔离**：Octarq 在数据层严格隔离域名所属组织。如果某个域名在多个租户间存在争议或冲突，路由查找引擎将 Fail-Closed 直接返回 HTTP 404 Not Found，杜绝跨租户劫持流量的风险。

## 基于访客属性的条件分流规则

点击短链详情中的 **添加规则**，无需更换公开短链即可根据访客特征精准分流：

- **地理位置 (GeoIP)**：根据 ISO 3166-1 alpha-2 标准国家代码分流（例如 `US` 流量导向美元结算页，`DE` 流量导向欧元区页面）。
- **设备类型**：识别访客终端为 `mobile`（手机）、`tablet`（平板）或 `desktop`（桌面电脑）。
- **操作系统**：探测访客平台（`ios`、`android`、`windows`、`macos`、`linux`），将移动用户直接导向 App Store 或 Google Play 下载地址。
- **浏览器语言**：读取请求头中的 `Accept-Language`（例如将 `zh-CN` 或 `ja-JP` 访客自动导向对应的多语言落地页）。

若来访流量未命中任何条件规则，系统将重定向至默认的 **Target URL**。

## 黏性 A/B 分流测试 (`splitAssign`)

Octarq 内置免 Cookie、轻量级的确定性 A/B 测试路由引擎：

1. 添加一条类型为 **Split** 的规则。
2. 设置各个实验变体的目标落地页地址及分配百分比 **权重**（1–100）。
3. **确定性哈希分配**：路由引擎结合匿名化后的访客指纹与短链 ID 计算哈希散列：
   ```
   bucket = sha256(fingerprint + "\n" + linkID) % 100
   ```
4. **访客黏性一致**：同一访客多次点击链接时将始终被稳定分配至同一变体，无需依赖第三方 Cookie 或客户端 JavaScript 脚本。
5. **余量流量回退**：若各变体权重之和不足 100%（例如变体 A 占 30%，变体 B 占 30%），剩余 40% 的余量流量将自动回退至短链原始的目标地址（对照组）。若累计权重超过 100%，系统在满 100% 处自动截断并安全运行，绝不抛出 500 异常。

## 访问密码、过期时间与点击上限

适用于内部资料分享或限量抢购活动：

- **密码保护**：开启并设定访问密钥。未验证的访客将看到简洁的密码输入表单。后端通过常量时间比对 (`subtle.ConstantTimeCompare`) 校验密码，阻断基于时序侧信道的暴力破解，并通过滑动窗口 IP 限流器（300 请求/分钟）抵御密码嗅探。
- **定时过期**：设定失效时间点（`ExpiresAt`）。到达时间后，访客将被重定向至指定的 **过期回退地址**（未设置则返回 HTTP 404）。
- **点击次数上限**：指定链接累计跳转上限（`ClickLimit`）。
- **边缘缓存优化**：针对配置了点击上限的短链，系统自动将边缘缓存 TTL 降至 5 秒，防止高并发下产生超额投递。
- **配额安全防护**：当工作区当月点击量超出可用配额时，批量计数器记录限额日志，重定向跳转逻辑依然平稳执行。

## 隐私合规分析与 UTM 渠道归因

短链的每一次跳转均可在保护访客隐私的同时，沉淀详尽的营销分析数据：

- **IP 匿名化脱敏**：系统在接入层对访客 IP 进行实时脱敏（IPv4 掩码至 `/24`，IPv6 清零后 80 位），原始 IP 绝不写入持久化数据库。
- **自动化 UTM 捕获**：访问链接时携带的渠道追踪参数（`utm_source`、`utm_medium`、`utm_campaign`、`utm_term`、`utm_content`）会自动提取并记录至分析日志，同时完整透传给目标落地页。
- **PV 与 UV 洞察**：支持在浏览量 (PV) 与基于每日加盐指纹计算的独立访客 (UV) 之间自由切换。
- **多维度下钻看板**：提供按日/小时的流量走势图、来源网站排行、流量渠道分类（直接访问、搜索引擎、社交网络、邮件推广、外链引流）、地域分布、操作系统及浏览器分布。

## 动态二维码与批量 CSV 导出

- **高清矢量二维码**：在短链详情侧边栏中可直接下载 PNG 或矢量 SVG 格式的二维码，亦可通过 API `GET /api/links/{id}/qr?size=512` 动态生成。
- **CSV 批量导出**：点击 **导出 CSV**（对应端点 `GET /api/links/export.csv`），一键下载当前工作区下所有短链的创建时间、目标地址、标签及累计点击量，无缝对接数据分析系统。

## 在出站邮件中启用短链自动替换

如需自动将工作区外发邮件中的超链接转换为可追踪短链，可前往 **日常运营 → 消息 → 邮件**，在 **Settings** 标签页的入站配置中勾选 **出站邮件自动短链化**。邮件中的本地地址与 `mailto:` 链接将自动排除。
