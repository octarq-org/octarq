Octarq 短链给每个目的地一个简短、可分享的地址。你可以按访客位置或设备分流、开展 A/B 测试、设置过期或密码、并统计每次点击——全部使用同一个公开链接。

## 创建短链接

1. 进入 **日常运营 → 营销 → 短链**（或按 `⌘K` / `Ctrl+K` 搜索“短链”）。
2. 点击 **新建短链**。
3. 输入目的地 **Target URL**（例如 `https://example.com/landing-page`）。
4. （可选）设置高级选项：
   - **Host**：选择已绑定的品牌域名，例如 `go.example.com`。留空时使用实例默认的短链域名。
   - **自定义 Slug**：输入易记的路径，例如 `summer-sale`。留空时 Octarq 会自动生成短小、安全的 Slug。
5. 点击 **创建短链**。

### 选择 Slug

输入自定义 Slug 前，Octarq 会先校验：

- **系统保留路径**如 `/admin`、`/api`、`/assets`、`/portal`、`robots.txt`、`favicon.ico` 不能用作 Slug。
- **实例保留关键字**（在 **实例控制台 → 短链设置** 中配置）也不允许使用。
- **同一域名下 Slug 必须唯一**。如果该 Slug 已被使用，系统会显示冲突，而不是创建重复链接。

## 使用品牌域名

品牌域名更易识别：

1. 在 [DNS 域名解析](/help/dns) 绑定并验证域名。
2. 创建或编辑链接时，从 **Host** 选择该域名。
3. 自定义域名只属于当前工作区。如果域名在多个工作区之间存在争议，Octarq 会把它当作不可用，避免把流量导错。

## 用条件规则分流访客

在链接详情里点击 **添加规则**，就可以在保持同一个短链的前提下，把不同访客送往不同目的地。规则可以按以下属性匹配：

- **位置**（国家/地区）
- **设备**（手机、平板、电脑）
- **操作系统**
- **浏览器语言**

如果没有匹配规则，Octarq 会把访客重定向到默认 **Target URL**。

## 测试变体（A/B）

Octarq 可以在不使用 Cookie 或客户端脚本的情况下分发流量：

1. 添加类型为 **Split** 的规则。
2. 为每个变体填写目的地和权重（1–100）。
3. Octarq 会把匿名化的访客指纹与链接 ID 一起哈希，让同一访客始终获得相近的结果。
4. 如果权重之和小于 100%，剩余流量会回退到主 **Target URL**；如果超过 100%，Octarq 会安全地把总量截断到 100%。

## 保护链接

为临时或敏感内容保护短链：

- **密码**：设置访问密钥。未验证的访客会先看到密码页，再被重定向。提交会做安全校验并限流。
- **过期时间**：选择日期和时间。时间过后，访客会前往你设置的 **过期回退地址**；如果你没设置，则返回未找到。
- **点击上限**：设置最大点击次数。Octarq 会让边缘缓存只保留几秒，以便在多节点间正确限制。
- **配额**：如果工作区达到月度配额，Octarq 会记录限制，但继续重定向现有链接。

## 跟踪点击

每个跳转都会生成不侵犯隐私的事件数据。Octarq 不存储原始 IP；访客地址会在保存前被匿名化。

你还可以查看：

- 页面浏览量和独立访客
- 来源站、渠道、国家/地区、操作系统和浏览器
- UTM 参数——Octarq 会记录并透传给目的地

## 二维码与导出

- **二维码**：在链接详情抽屉里下载 PNG 或 SVG，或使用 `GET /api/links/{id}/qr?size=512`。
- **CSV 导出**：用 **导出 CSV** 导出全部链接、目的地、标签和点击数，或使用 `GET /api/links/export.csv`。

## 自动包装邮件链接

如需把发出的邮件中的链接替换为短追踪链接，请打开 **日常运营 → 消息 → 邮件 → 设置**，开启 **在发出的邮件中自动包装链接**。内部链接和 `mailto:` 链接会被保留不变。
