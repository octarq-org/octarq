Octarq Links gives every destination a short, shareable address. You can route visitors by location or device, run an A/B test, set an expiry or password, and measure every click—without changing the public URL.

## Create a Short Link

1. Go to **Operations → Marketing → Links** (or press `⌘K` / `Ctrl+K` and search "Links").
2. Click **New Link**.
3. Enter the destination **Target URL** (for example, `https://example.com/landing-page`).
4. (Optional) Set advanced options:
   - **Host**: Choose an owned domain such as `go.example.com`. If you leave it unset, the link uses your instance’s default short domain.
   - **Custom Slug**: Enter your own path, such as `summer-sale`. If you leave it blank, Octarq creates a short, secure slug for you.
5. Click **Create Link**.

### Choosing a Slug

When you enter a custom slug, Octarq checks it before saving:

- **System paths** such as `/admin`, `/api`, `/assets`, `/portal`, `robots.txt`, and `favicon.ico` are reserved.
- **Instance keywords** blocked in **Instance Console → Link Settings** are not allowed.
- **Slugs must be unique** for each domain. If the slug is already used on the selected host, Octarq shows a conflict instead of creating it.

## Use a Custom Domain

A branded domain makes links easier to recognize:

1. Connect and verify your domain in [DNS Management](/help/dns).
2. When creating or editing a link, choose your domain from **Host**.
3. Custom domains are private to your workspace. If a domain is contested across workspaces, Octarq treats it as unavailable rather than redirecting the wrong visitors.

## Route Visitors with Conditions

Click **Add Rule** on any link to send visitors to different destinations while keeping the same short URL. Rules can match:

- **Location** (country)
- **Device** (phone, tablet, computer)
- **Operating system**
- **Browser language**

If no rule matches, Octarq sends the visitor to the default **Target URL**.

## Test Variants (A/B)

Octarq can split traffic between destinations without cookies or client-side scripts:

1. Add a rule of type **Split**.
2. Enter each variant’s destination and weight (1–100).
3. Octarq hashes an anonymized fingerprint together with the link ID so each visitor gets a stable result.
4. If the weights add up to less than 100%, the remaining traffic goes to the main **Target URL**. If they add up to more, Octarq caps the total at 100%.

## Protect a Link

Protect time-sensitive or private links:

- **Password**: Set a passphrase. Visitors see a passcode page before they are redirected. Submissions are rate-limited.
- **Expiry**: Choose a date and time. After that, visitors go to your **Expired URL**, or receive a not-found response if you did not set one.
- **Click limit**: Set a maximum number of clicks. Octarq keeps cached copies for only a few seconds so the limit is respected across edge nodes.
- **Quota**: If your workspace reaches its monthly quota, Octarq records the limit but continues to redirect existing links.

## Track Clicks

Every redirect creates a privacy-preserving event. Octarq does not store raw IP addresses; visitor addresses are anonymized before they are saved.

You can also review:

- Page views and unique visitors
- Referrers, channels, countries, systems, and browsers
- UTM parameters, which Octarq records and passes through to the destination

## QR Codes and Exports

- **QR code**: Download a PNG or SVG from the link details drawer, or use `GET /api/links/{id}/qr?size=512`.
- **CSV export**: Export all links, destinations, tags, and click counts from **Export CSV**, or use `GET /api/links/export.csv`.

## Auto-Wrap Email Links

To replace links in outgoing email with short tracking links, open **Operations → Messaging → Mail → Settings** and turn on **Auto-wrap links in outgoing mail**. Internal links and `mailto:` links are left unchanged.
