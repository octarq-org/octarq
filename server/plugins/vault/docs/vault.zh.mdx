在 **设置 › 集成中心** 中集中保存和管理第三方服务凭据、环境变量、SSH 私钥、数据库密码、TLS 证书与 2FA 验证码。

## 工作区凭证库

页面只有一个工作区凭证库。界面中没有个人凭证库，也没有作用域切换器。

- **工作区**：存放当前组织共享的三方集成、环境密钥与服务令牌。
- 普通成员可查看元信息、测试连通性、查看版本历史与动态口令。
- 管理员可新建、编辑、查看明文、回滚版本、设为默认集成、批量导入 `.env` 与管理服务令牌。
- 所有者可导出密钥或永久删除条目。

## 添加凭证条目

1. 打开 **设置 › 集成中心**。
2. 选择目标集合与环境（`default`、`prod`、`staging`、`dev`）。
3. 点击 **新建条目**。
4. 选择分类与模板，例如 OpenAI、Stripe、S3、键值对密钥或 2FA 动态口令。
5. 填写名称、可选键名与必填字段。
6. 点击 **创建**。

## 查看明文、测试与版本回滚

- 列表视图默认隐藏所有涉密字段。每个条目都会生成可一键复制的 `vault://` 引用标识。
- 点击 **查看明文** 读取或复制当前值。每次查看都会写入审计日志。
- 对支持测试的三方集成、数据库、SSH 密钥或证书，可点击 **测试** 验证有效性。测试不会暴露明文。
- 编辑密钥会生成新的不可变版本。打开 **版本历史** 可查看变更记录，点击 **回滚** 可恢复历史版本。

## 导入与导出 `.env`

1. 选择目标集合与环境。
2. 点击 **导入** 并粘贴 `KEY=VALUE` 内容或 JSON。系统会批量创建或更新密钥。
3. 工作区所有者可点击 **导出**，按当前集合导出 `.env` 或 JSON 文件。

## 服务令牌（Service Token）

在 **服务令牌** 标签页创建只读机读令牌。令牌仅限指定的集合、环境与目录前缀。CI/CD 流水线或外部应用可通过 `/api/vault/raw` 安全拉取配置，无需用户登录态。

```bash
curl -H "Authorization: Bearer octvq_..." "https://your-octarq-host/api/vault/raw?format=env"
```

:::tip
服务令牌仅能读取所绑定集合、环境及目录前缀下的工作区条目。它无法访问实例全局密钥。
:::

## 实例凭据库

实例管理员可打开 **实例设置**（`/instance/settings`）中的 **实例凭据库** 区域。该区域统一管理实例级全局密钥，例如 OAuth 客户端密钥（`instance.oauth.google`、`instance.oauth.github`）与监控指标令牌（`instance.metrics_token`）。
