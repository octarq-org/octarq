在 **设置 › 集成中心** 中集中保存和管理第三方服务凭据、环境变量、SSH 私钥、数据库密码、TLS 证书与 2FA 验证码。

## 添加凭证条目

1. 打开 **设置 › 集成中心**。
2. 选择目标保险库或项目集合及环境（如 `default`、`prod`、`staging`、`dev`）。
3. 点击 **添加条目**。
4. 选择三方服务连接器模板或通用密钥类型。
5. 填写名称与字段内容，点击 **保存**。

## 查看明文与版本回滚

- 列表视图默认隐藏所有涉密字段。
- 点击 **查看明文** 读取或复制当前值，每次查看都会写入审计日志。
- 编辑密钥会生成新的不可变版本。打开 **版本历史** 可查看变更记录并一键回滚到任意历史版本。

## 导入与导出 `.env`

1. 选择目标集合与环境。
2. 点击 **导入 .env** 并粘贴 `KEY=VALUE` 内容，即可批量创建或更新密钥。
3. 点击 **导出** 可按当前作用域导出 `.env` 或 JSON 文件。

## 服务令牌（Service Token）

在 **服务令牌** 标签页创建仅限指定集合、环境与目录前缀的机读令牌，供 CI/CD 流水线或外部应用安全拉取配置。
