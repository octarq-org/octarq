LLM 网关让工作区连接到模型后端。AI 功能使用网关。AI 功能不保存自己的密钥。

没有 provider 的工作区没有 AI。平台不为工作区使用实例凭据。

## 添加 provider

**工作区 → LLM 网关 → 添加 provider** 打开 provider 表单。

1. 输入名称。名称供运维人员识别。
2. 选择后端。
3. 输入 API 密钥。
4. 可选：输入代理或本地模型的基址。
5. 可选：输入默认模型和廉价模型。
6. 选择 **保存**。

第一个 provider 自动成为默认 provider。

本地后端（例如 Ollama）不需要 API 密钥。

## 测试 provider

在 provider 旁选择 **测试**。网关向该后端发送一次小请求。

- **OK**：密钥、基址和模型可用。
- **错误**：后端返回的消息说明原因。

## 选择默认 provider

默认 provider 服务工作区的全部 AI 请求。

在 provider 旁选择 **设为默认**。一个工作区同时只有一个默认 provider。

先选择另一个默认 provider，再删除当前默认 provider。没有默认 provider 的工作区拒绝 AI 请求。

## 设置模型价格

**模型价格** 设置每百万 token 的价格。

输入后端使用的模型标识。输入输入价格、输出价格和推理价格。选择 **保存价格**。

带预算的 AI 功能拒绝没有价格的模型。先添加价格，再使用该模型。

价格为零表示该模型没有 token 费用。

## 访问权限

LLM 网关页面需要工作区管理员角色。

成员不能读取或修改 provider 凭据。
