模型网关让工作区连接到模型后端。AI 功能使用网关。AI 功能不保存自己的密钥。

没有提供商的工作区没有 AI。平台不为工作区使用实例凭据。

## 添加提供商

**设置 › 模型网关**，然后选择 **添加提供商**，打开提供商表单。

1. 输入名称。名称供运维人员识别。
2. 选择后端。
3. 输入 API 密钥。
4. 可选：输入代理或本地模型的接口地址。
5. 可选：选择默认模型和廉价模型。
6. 选择 **保存**。

表单从提供商读取模型列表。不要手动输入模型名。claude 密钥未填接口地址时，读取 Anthropic 的模型列表。

第一个提供商自动成为默认提供商。

本地后端（例如 Ollama）不需要 API 密钥。

## 测试提供商

在提供商旁选择 **测试**。网关向该后端发送一次小请求。

- **OK**：密钥、接口地址和模型可用。
- **错误**：后端返回的消息说明原因。

## 选择默认提供商

默认提供商服务工作区的全部 AI 请求。

在提供商旁选择 **设为默认**。一个工作区同时只有一个默认提供商。

先选择另一个默认提供商，再删除当前的默认提供商。没有默认提供商的工作区拒绝 AI 请求。

## 设置模型价格

**模型价格** 设置每百万 token 的价格。

选择 **添加价格**。输入后端使用的模型标识，再输入输入价格、输出价格和推理价格。选择 **保存**。

带预算的 AI 功能拒绝没有价格的模型。先添加价格，再使用该模型。

价格为零表示该模型没有 token 费用。

## 使用编程代理

编程代理可以使用工作区的模型提供商。

Codex、Cline、aider 和 opencode 使用 OpenAI API 格式。工作区在 `/v1` 提供该格式。

代理需要三个设置：

1. 接口地址：工作区地址，再加 `/v1`。
2. API 密钥：工作区令牌。由管理员生成令牌。
3. 模型：由代理读取列表。不要输入模型名称。

代理请求 `GET /v1/models`，并显示提供商提供的模型。然后代理把每一轮请求发送到 `POST /v1/chat/completions`。

网关把聊天补全请求原样转发给提供商。工具调用、流式输出和结构化输出都能继续工作。

## 使用 Codex

Codex 使用 OpenAI Responses 格式。工作区在 `/v1/responses` 提供该格式。

Codex 0.167 不再加载聊天格式。它需要这条路由。

编辑 `~/.codex/config.toml`：

```toml
model = "<列表中的模型>"
model_provider = "octarq"

[model_providers.octarq]
name = "octarq"
base_url = "<工作区地址>/v1"
env_key = "OCTARQ_TOKEN"
wire_api = "responses"
```

启动 Codex 前，把 `OCTARQ_TOKEN` 设为工作区令牌。

网关把每一轮请求转换为提供商格式，再把答案转换回来。工具调用和流式输出都能继续工作。

## 使用 Claude Code

Claude Code 使用 Anthropic Messages 格式。工作区在 `/v1/messages` 提供该格式。

设置三个环境变量：

1. `ANTHROPIC_BASE_URL`：工作区地址。
2. `ANTHROPIC_AUTH_TOKEN`：工作区令牌。
3. `ANTHROPIC_MODEL`：提供商提供的模型。先在模型页面读取列表。

Claude Code 把工具调用和流式输出发到同一组路由。网关把它们转换为提供商格式，再把答案转换回来。

请求中的模型原样传给提供商。把 `ANTHROPIC_MODEL` 设为提供商提供的模型。名称错误时返回提供商的错误。

模型页面有一个「读取模型列表」按钮。它显示提供商提供的模型名称。原生 Anthropic 密钥同样可以使用这个按钮。

:::note
提供商的密钥保存在工作区内。代理从不持有密钥。
:::

## 使用 opencode

opencode 自己找到工作区。它读取 `/.well-known/opencode`，运行该文档指定的命令，然后加载提供商配置。配置里列出提供商提供的全部模型。你不需要输入模型名。

1. 在令牌页面创建一个工作区令牌。
2. 运行 `opencode auth login <工作区地址>`。
3. opencode 询问时填入令牌。

在第 2 步之前设置 `OCTARQ_TOKEN`，就可以跳过这一步询问。命令读取该变量，并把它存为凭据。

在控制台添加模型后，运行 `opencode reload`。新模型随即出现在选择列表中。

`curl <工作区地址>/.well-known/opencode` 显示 opencode 读取的同一份文档。

## 访问权限

模型网关页面需要工作区管理员角色。

成员不能读取或修改提供商凭据。
