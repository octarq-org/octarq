Octarq 邮箱为你的工作区在自定义域名上提供专属邮件地址。你可以通过 Webhook 接收事务性入站邮件、通过 Catch-All 规则路由未配置的地址，并通过外部 SMTP 发件服务发送出站邮件。

:::note
Octarq 通过 Webhook 接收邮件，并通过外部 SMTP 服务器发送出站邮件。系统未内置 IMAP 或 POP3 邮件服务。
:::

## 创建邮箱

1. 进入 **日常运营 → 消息 → 邮件**，切换到 **邮箱** 标签页（或按 `⌘K` / `Ctrl+K` 搜索“邮件”）。
2. 点击 **新建邮箱**。
3. 从 [DNS 域名解析](/help/dns) 中选择已验证的域名，并输入地址前缀（例如 `support`）。
4. 点击 **创建邮箱**。

发送至该地址的入站邮件将直接归入该邮箱。

## 用 Catch-All 路由接收邮件

Catch-All 路由可捕获发送至尚未单独创建的地址的邮件：

1. 进入 **日常运营 → 消息 → 邮件**，切换到 **设置** 标签页。
2. 开启 **启用 Catch-All 路由**。
3. （可选）在 **保留邮箱前缀** 中输入以逗号分隔的前缀（例如 `admin, postmaster, abuse, security`），这些地址将跳过自动创建。
4. 点击 **保存更改**。

开启 Catch-All 后，发送至已验证域名上未配置地址的邮件会自动创建带有 `auto (catch-all)` 标记的邮箱。保留前缀会被排除，以保护系统核心地址。

## 接收入站邮件

Octarq 通过来自边缘邮件服务的 HTTPS Webhook 接收入站邮件。

### 配置 Webhook 端点

1. 进入 **日常运营 → 消息 → 邮件**，切换到 **设置** 标签页。
2. 在 **入站配置** 下复制当前工作区的 **入站 Webhook URL**。
3. 配置你的邮件服务商（例如 Cloudflare Email Routing、SendGrid 或 Mailgun），将接收到的邮件 POST 至该 Webhook 地址。

请求通过 URL 路径中的密钥令牌进行鉴权。

### 邮件大小限制

Octarq 接收邮件时遵循以下限制：

- **邮件总大小**：单封邮件上限 25 MiB。
- **附件与内容分块**：单个文件上限 10 MiB，单封邮件最多 200 个分块。
- **容错处理**：如果传入邮件的标头或分界格式异常，Octarq 仍会以 `(unparseable message)` 为主题保存邮件，确保数据不丢失。

## 配置出站 SMTP 发件服务

如需从工作区发送事务性通知或成员邀请邮件：

1. 进入 **日常运营 → 消息 → 邮件**，切换到 **设置** 标签页。
2. 在 **SMTP 发件配置** 下，点击 **添加 SMTP 发件服务**。
3. 填入 SMTP **主机**、**端口**（`587` 或 `465`）、**用户名**、**密码** 及默认 **发件人邮箱**。
4. 点击 **保存发件服务**。

凭证在存储时全程加密。系统具备活跃的 SSRF 拦截防护，自动阻断针对私有网络、本地回环地址以及云厂商内部元数据端点的出站连接。

## 测试连接与排查故障

添加发件服务后，验证你的凭证是否有效：

1. 在 **SMTP 发件配置** 列表中找到你的发件服务。
2. 点击 **测试连接**。
3. 查看测试结果。Octarq 会连接到服务器执行 TLS 握手，并立即反馈状态。

如果连接测试失败，请排查以下原因：

- **认证失败**：请检查用户名、密码或 API 密钥是否正确。
- **连接超时**：请核对主机地址与端口（通常使用 `587` 进行 STARTTLS 或 `465` 进行 TLS）。
- **安全拦截**：指向私有网络或内部 IP 地址的出站连接会被 SSRF 防护直接拦截。

## 管理退信与黑名单

Octarq 跟踪投递失败记录，保护发信域名信誉：

- **硬退信与垃圾邮件投诉**：当邮件永久投递失败或收到垃圾邮件投诉时，Octarq 会自动将收件地址加入工作区黑名单。
- **软退信**：临时投递问题（例如邮箱容量已满）仅记录在活动日志中并触发告警，不会将地址加入黑名单。
- **手动黑名单**：进入 **日常运营 → 消息 → 邮件** 打开 **黑名单** 标签页，即可添加或移除地址。发送至黑名单地址的出站邮件会在发出前被直接拦截。

## 自动包装出站链接

无需手动修改链接即可追踪外发邮件中的点击：

1. 进入 **日常运营 → 消息 → 邮件**，切换到 **设置** 标签页。
2. 开启 **在发出的邮件中自动包装链接**。
3. 点击 **保存更改**。

HTML 邮件中的外部链接会自动转换为带有点击追踪的 [短链](/help/short-links)。同域名内部链接与 `mailto:` 链接保持原样不变。

:::caution 本功能为 Pro 专属功能
Octarq 社区版将邮件正文与附件保存在本地数据库中。在 **Octarq Pro** 中，传入邮件与附件可直接转存至 Amazon S3、Cloudflare R2 或 MinIO 对象存储。
:::
